# Moodify Power Preference Annotation Guideline v0.1

## 任务
比较同一原始音乐片段的两个处理版本，判断哪一个更具有力量感。

## 力量感
力量感指受控能量、冲击、重量、推进感和决定性。它不等于更响、更刺耳、更压缩或低频更多。

## 操作
1. 先完整听 A，再完整听 B；必要时可重复。
2. 忽略轻微响度差；若响度差明显影响判断，选择“无法判断”并标记响度异常。
3. 选择：A 更有力量 / B 更有力量 / 相近 / 无法判断。
4. 回答辅助问题：获胜版本的清晰度是否明显更差？

## 判断优先级
- 是否有更明确的冲击与推进；
- 是否具有重量但不浑浊；
- 是否保持主体和层次清晰；
- 是否更像音乐本身的力量，而不是技术刺激。

## 不要做
- 不要根据波形图、文件名或参数判断；
- 不要默认更响就是更有力量；
- 不要在听不出差异时强行选择。
