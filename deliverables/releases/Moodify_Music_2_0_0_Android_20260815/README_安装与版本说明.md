# Moodify Music Android 2.0.0

发布日期：2026-08-15

## 安装

在 Android 8.0（API 26）或更高版本设备上安装 `Moodify_Music_2.0.0_Android_20260815.apk`。

从 Moodify 1.0.0-rc.2 升级时可以直接覆盖安装；两个版本使用相同的内部 Debug 签名证书，覆盖安装会保留本地数据。

## 首次使用

1. 打开 App，等待公共曲库载入。
2. 首次进入不会自动播放，点击 Play 开始。
3. 上下滑动切换歌曲；播放启动后会连续播放，主动暂停后切歌保持暂停。
4. 点击心形收藏当前歌曲；点击“＋”加入已有歌单或创建新歌单。
5. 子界面左侧边缘向内滑打开抽屉，右侧边缘向内滑返回 Play。

## 缓存

App 会在后台预取最多 10 首歌曲的起播数据，并使用上限 512 MB 的磁盘 LRU 缓存。缓存可以被 Android 系统或用户安全清理，清理后会自动重新建立。

## 文件完整性

安装前可使用 `SHA256SUMS.txt` 校验 APK、日志和说明文件。此包是内部体验固定版，不是应用商店生产签名版本。
