# Human Policy Gate
## Contribution Rewards

The software may enforce rules, but it must not invent the economic policy.

Before public production rewards are enabled, human protocol leadership should approve:

- task categories;
- reward ranges;
- maximum reward per task if any;
- total contribution reward budget per epoch/campaign;
- who can review;
- whether contributor profiles are public;
- evidence/IP terms;
- distribution cadence.

If these are not yet approved, Codex should:
- build the system;
- use development fixtures;
- keep production reward publishing disabled or clearly gated;
- report the missing policy.

## Human review principle

AI can assist with:
- evidence summarization;
- test execution;
- duplicate detection;
- rubric scoring.

AI should not be the sole final approver for material MOOD rewards in v1.
