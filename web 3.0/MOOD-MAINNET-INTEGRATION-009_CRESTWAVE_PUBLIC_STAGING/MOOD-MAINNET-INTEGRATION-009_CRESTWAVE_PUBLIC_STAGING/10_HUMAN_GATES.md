# Human Gates

The following actions require explicit human approval and are outside Package 009:

1. merge staging branch into `main`;
2. repoint `crestwavecoin.com` root domain;
3. deploy MoodGenesisDistributor;
4. approve a Merkle snapshot for production;
5. set a production Merkle root;
6. fund a Distributor with MOOD;
7. transfer treasury MOOD;
8. enable public claim;
9. transfer contract ownership;
10. renounce ownership;
11. change liquidity;
12. use any private signing key.

Codex may prepare documentation and commands for future packages, but must not execute those actions in this package.
