# Human Classification Gate
## Treasury Wallet Labels & Tokenomics

Codex must not decide who owns/control wallets based on chain heuristics.

Human approval is required before public labels such as:

- Founder
- Team
- Treasury
- Foundation
- Ecosystem
- Liquidity Reserve
- Strategic Reserve
- Contributor Reserve

are attached to a real address.

### Approval record template

```text
Address:
Public Label:
Category:
Purpose:
Control Model:
Publicly Disclose: YES / NO
Evidence / Decision Source:
Approved By:
Approved At:
```

### Token allocation

Likewise, a public token allocation chart requires an approved allocation policy.

Do not treat planning tables or brainstorming percentages as protocol canon.

### Circulating supply

A numeric circulating supply requires an approved methodology.

Until then:
- total supply is factual;
- account balances are factual;
- circulating supply remains unpublished.

### Future Safe migration

If the project later creates Safe treasury accounts, use a new human-approved task/package to:
- create Safe;
- define signers;
- define threshold;
- move funds.

Package 007 only prepares metadata/read support.
