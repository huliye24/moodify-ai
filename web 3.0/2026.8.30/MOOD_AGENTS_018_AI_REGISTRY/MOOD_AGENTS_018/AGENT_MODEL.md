# AGENT MODEL

```text
Agent
├── Identity
├── Operator
├── Capabilities
├── Runtime
├── Status
├── Task Runs
├── Proofs
└── Reputation
```

## Separation

### Identity
谁是这个 Agent。

### Runtime
它当前运行在哪里 / 用什么模型。

### Operator
谁对它负责。

### Capability
它被允许做什么。

### Proof
它做过什么，可验证证据是什么。

### Reputation
协议对其历史质量的累计评价。
