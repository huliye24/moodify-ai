# MOOD AGENTS 018 — AI Agents Registry

**Package ID:** `MOOD-AGENTS-018`  
**Target repository:** `huliye24/moodify-ai`  
**Depends on:** `MOOD-FOUNDATION-011` → `MOOD-NETWORK-017`

## Mission

把 AI 从“开发工具”正式升级为 MOOD 网络中的可识别参与者。

核心路径：

```text
AI Agent
   ↓
Agent Identity
   ↓
Capabilities
   ↓
Tasks
   ↓
Proof / Evidence
   ↓
Contribution
   ↓
Status / Reputation
   ↓
Network Activity
```

018 不做“自动赚钱机器人”，也不允许 AI 绕过 Contribution Review。

---

## Core Principles

### 1. Agent is a network actor
AI Agent 应该有稳定 ID、能力、状态、Owner / Operator 和可验证活动。

### 2. Agent identity ≠ wallet identity
Agent 可以由 Resident / Organization / System 运营，但 Agent 自己不是自然人。

### 3. Proof before reputation
Agent 不能因为“在线”就获得 Reputation。

### 4. Human accountability
每个 Agent 必须有明确 operator / owner / controller。

### 5. No silent autonomy
Agent 不能静默：
- 批准 Contribution
- 修改 Reputation
- 触发 Token 分发
- 进行资金操作

### 6. Real agents only
Network 页面只能显示真实注册 Agent，不允许伪造数量。
