# CAPABILITY POLICY

Capabilities should be narrow and auditable.

Allowed examples:

- audio-analysis
- research
- documentation
- code-assistance
- proof-verification
- curation
- task-assistance
- node-operations

Each capability should define:

```text
Inputs
Outputs
Allowed Tools
Forbidden Actions
Evidence Requirements
Human Review Requirements
```

Never register:

```text
unlimited
superuser
autonomous-funds
governance-owner
```
