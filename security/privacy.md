# Moodify Privacy Policy

## Privacy Principles

Moodify is committed to protecting user privacy while delivering AI-powered audio analysis.

## User Data

### Ownership

**User audio content belongs to the user.**

- Users retain full ownership of uploaded audio
- Moodify does not claim rights to user content
- Analysis results are user property
- Moodify acts as a processing service only

### Data Usage

**Current Practice**:
- Audio is processed for analysis only
- Raw audio is not retained after processing
- Results are stored for user access
- No use for purposes other than stated

**What We Do NOT Do**:
- Sell user data
- Use audio for advertising
- Share with third parties
- Train models on user content without consent

## Model Training

### Current Status

**Moodify does not use user uploads for model training.**

All model training uses:
- Public domain audio
- Licensed training datasets
- Synthetic test data
- Consented research data

### Future Training Policy

**Any use of user data for model training requires:**

1. **Explicit User Authorization**
   - Opt-in consent
   - Clear explanation of use
   - Ability to withdraw consent
   - No default opt-in

2. **Clear Rules**
   - Anonymization requirements
   - Aggregation minimums
   - Purpose limitations
   - Time restrictions

3. **Transparency**
   - Published training dataset composition
   - Regular transparency reports
   - User-accessible impact assessments

## Copyright Awareness

### Respect for Rights

Moodify respects:

- **Music Copyright**: Original works and recordings
- **Creator Rights**: Composers, performers, producers
- **Enterprise Ownership**: Corporate audio assets
- **User Rights**: Personal and licensed content

### User Responsibilities

Users must:

- Upload only owned or licensed content
- Respect copyright laws
- Not upload pirated content
- Comply with platform terms of service

### Enterprise Considerations

For enterprise users:

- Verify content ownership
- Maintain license documentation
- Implement content policies
- Monitor compliance

### Content Guidelines

**Acceptable**:
- Original compositions
- Licensed music
- Public domain recordings
- User-created content
- Test audio (short duration)

**Not Acceptable**:
- Pirated content
- Unauthorized recordings
- Content violating laws
- Malicious uploads
