# W07 UI Interaction Contract

```text
VISUAL_REDESIGN = FORBIDDEN
```

允许的视觉变化仅限：

- selected row state
- focus state
- drag target highlight
- context menu
- confirmation dialog
- batch action affordance
- small result feedback

## 禁止

- 重做首页
- 新底部控制条大改
- Spotify-style dense interface
- large toolbar
- engineering console
- Ear/DSP/cloud status

## Principle

更多能力通过：

```text
右键
双击
拖拽
多选
```

而不是增加一排新按钮。
