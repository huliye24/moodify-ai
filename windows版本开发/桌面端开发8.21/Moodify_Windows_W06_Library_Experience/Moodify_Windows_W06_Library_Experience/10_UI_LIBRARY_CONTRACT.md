# W06 UI Library Contract

```text
VISUAL_REDESIGN = FORBIDDEN
```

## Sidebar

允许逐步形成：

```text
音乐库
- 全部歌曲
- 最近添加
- 最近播放
- 收藏

我的歌单
- ...
```

但优先服从现有 sidebar。

## Search
一个轻量搜索框即可，不做 AI prompt box。

## Track Row
保持轻量：

```text
Title
Artist
Album(optional)
Duration
Availability
```

## Actions
优先：
- double click
- context menu
- subtle row action

避免每行堆很多按钮。

## Home
首页继续以 PLAY 为中心。

W06 管理功能进入 secondary views，不把首页变成数据库界面。
