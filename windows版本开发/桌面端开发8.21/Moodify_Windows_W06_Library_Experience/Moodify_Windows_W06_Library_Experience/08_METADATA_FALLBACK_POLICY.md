# Metadata Fallback Policy

## Title
```text
embedded title
→ filename stem
→ 未知歌曲
```

## Artist
```text
embedded artist
→ 未知艺术家
```

## Album
```text
embedded album
→ 未知专辑 / omit
```

## Duration
```text
unknown → --:--
```

## Long Text
需要 ellipsis / tooltip / safe layout。
