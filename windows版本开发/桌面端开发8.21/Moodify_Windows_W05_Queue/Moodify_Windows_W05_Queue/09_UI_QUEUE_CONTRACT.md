## 最小 Queue Surface

可以使用现有 sidebar 的“当前播放”区域扩展。

推荐层级：

```text
当前播放
  当前 Track

接下来播放
  Track
  Track
  Track
```

## Track Actions

Library / Playlist Track context menu 可加入：

```text
播放
下一首播放
添加到播放队列
添加到歌单 >
```

## Queue Item Actions

```text
播放此项
移出播放队列
```

## Queue Reorder

```text

```

## Clear

