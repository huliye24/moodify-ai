# Moodify Desktop Phase 1 — Closure Rules

MFD-008 是 Phase 1 的终点。

---

## If GO

Phase 1 closes as:

```text
Moodify Desktop 0.1 Alpha
```

后续不要立刻继续堆功能。

建议先进入：

```text
Alpha feedback
→ crash / reliability evidence
→ listening evidence
→ usage evidence
→ entropy reduction
```

然后再决定 Phase 2。

---

## If CONDITIONAL GO

Phase 1 暂时进入：

```text
Controlled Alpha
```

限制：

- tester scope
- known blockers
- no broad public release

---

## If NO-GO

不要宣布 Alpha。

建立：

```text
MFD-FIX-xxx
```

只修阻塞项。

修复后重新进入 MFD-008 对应 Gate。

---

## Do not redefine success

Phase 1 的成功不是：

- 功能很多
- UI 很复杂
- 技术词很多

成功是：

> **Windows 用户能安装 Moodify，按下 Play，稳定听到 Moodify 提供的音乐，并且系统在基础故障下可恢复。**
