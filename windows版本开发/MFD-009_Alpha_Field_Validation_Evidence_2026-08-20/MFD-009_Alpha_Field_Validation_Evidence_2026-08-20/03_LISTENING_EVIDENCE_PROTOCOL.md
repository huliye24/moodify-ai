# MFD-009 Listening Evidence Protocol

## Purpose

Determine whether listeners can perceive and prefer Moodify's playback result.

Not a marketing study.

Not a scientific publication.

---

## Pair

```text
Reference
Moodify Version
```

Randomize A/B assignment.

Avoid revealing which is which.

---

## Loudness

Where feasible:

> loudness-match enough to prevent “louder = better” from dominating.

Record method.

Do not secretly normalize in a way that changes the product result without documenting it.

---

## Questions

1. Which would you choose to continue listening to?

```text
A
B
No clear preference
```

2. Which sounds more comfortable?

```text
A
B
No clear difference
```

3. How obvious is the difference?

```text
Clear
Slight
No clear difference
```

4. Optional one-line comment.

---

## Results

Per track:

```text
N
Moodify preference
Reference preference
No preference
Clear difference
Slight difference
No difference
```

Aggregate only with sample size visible.

---

## Do Not Claim

Do not conclude:

> Moodify improves all music.

Allowed conclusion example:

> In this Alpha cohort and tested tracks, listeners preferred the Moodify version in X/Y comparisons, with Z no-preference responses.

Keep evidence scoped.
