=== PROJECT OVERVIEW ===

Moodify is an AI music post-processing engine. It takes AI-generated music
(from Suno/Udio) as a "raw wave field", diagnoses its 5-dimensional wave state
(18 audio parameters), matches to emotion-targeted DSP chains (8 emotions x 15 params),
applies processing via pedalboard, and outputs emotionally enhanced music.

Metaphor: AI music = film negative, Moodify = darkroom developing the photograph.

Create MoodifyDSPChain class with method:
  process(audio: np.ndarray, sr: int, params: dict) -> np.ndarray

Map the 15 craft params to pedalboard effects:
- P01-P03 (vocal presence): pedalboard.PeakFilter(frequency_hz=P01, gain_db=P02, q=P03)
- P04-P05 (low warmth): pedalboard.LowShelfFilter(cutoff_frequency_hz=P04, gain_db=P05)
- P06-P09 (dynamics): pedalboard.Compressor(threshold_db=P09, ratio=P06, attack_ms=P07, release_ms=P08)
- P10-P12 (space): pedalboard.Reverb(room_size=P11, damping=0.5, wet_level=P11, dry_level=1-P11, width=P12)
- P13 (harmonic): pedalboard.Distortion(drive_db=P13*20) -- convert 0-1 to drive
- P14-P15 (air): pedalboard.HighShelfFilter(cutoff_frequency_hz=P14, gain_db=P15)
- Add pedalboard.Gain for output level
- Add pedalboard.Limiter as safety

Output must be same shape and sample rate as input.
Handle mono and stereo audio.
Test by constructing a chain and processing a numpy zeros array.
