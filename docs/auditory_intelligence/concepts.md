# 概念（DSK-MFY-AUDITORY-INTELLIGENCE-RECLASSIFICATION-001）

## 从"后处理"到"听觉智能"

旧框架：输入音频 → 处理 → 输出"更好的"音频。处理即产品身份。

新框架：Moodify 的核心是**听觉观察、表示、判断、验证与学习**。
处理系统是干预仪器，用于产生受控变化与训练相关证据。

## 责任分离

- **观察**回答"声音里发生了什么"：解码、波形、线性/对数频谱、响度、
  峰值与动态、频谱、立体声与相位、时间局部观察。
- **表示**回答"机器如何描述听到的内容"：类型化观察、时间/频率区域、
  严重度、置信度、证据引用、机器可读特征。
- **判断**回答"这是缺陷、风险、有意特征还是未决歧义"：技术风险、
  目标、护栏、置信度、不确定性、请求人耳听音。
- **干预实验室**回答"为检验或改善声音施加了什么受控变更"：EQ、
  压缩、限幅、去噪、立体声、相位修复、音色平衡、瞬态、插件链、
  Audacity 操作、候选生成。
- **验证**回答"改变了什么、改变多少、是否达成目标且未造成新损伤"：
  相同前后扫描、原始 delta、响度归一化 delta、风险标志、技术评估、
  工作流决策、证据 manifest。
- **学习**回答"系统能从案例学到什么"：接受/拒绝候选、成对偏好、
  干预结果、人耳标注、失败案例、数据集资格、标注质量、训练导出。

## 为什么处理仍保留但改变角色

处理是观察的触发器与学习的原料。删除处理能力会破坏生产与证据历史；
保留但重新定位为干预实验室。Audacity 是外部工作台，Moodify 不与其竞争。

## 为什么技术成功不等于艺术批准

信号指标无法推导"好听/有情感/有音乐性"。技术对比只能产生
PASS_TO_LISTENING 之类的**工作流**决策；艺术接受只能由人耳听音评估授予。
