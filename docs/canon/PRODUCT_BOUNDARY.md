# PRODUCT BOUNDARY — Moodify

**Canon v1.0（W01-P01, 2026-08-17）**

## External Product

**Name:** Moodify Music / Moodify Player

**Primary user action:** PLAY

**Public promise（现状声明，非远景承诺）：**
Moodify 提供以 PLAY 为核心的音乐聆听体验。来源可以是本地文件或云端准备曲目；
云端准备（识别、分析、重建、渲染）是内部生产环节，不要求用户理解。

## Internal Systems

以下均为内部能力，除非人类权威显式改变：

- Moodify Ear / Auditory Intelligence
- audio analysis
- stem separation
- judgment
- controlled intervention
- preset decision
- verification
- evidence
- learning
- cloud production（intake → job → storage → compute → render → delivery）

## User-visible complexity rule

用户不应需要理解内部处理即可获得核心播放体验。

## Non-goals for current public surface

- 公开研究仪表盘
- 把内部状态机暴露为产品 UX
- 强迫用户选择工程预设
- 把 Ear 作为第二个公开产品
- 用未验证的云端能力作为宣传点

## Evidence boundary

不得声称云端能力可用，除非 W01-P00 或之后运行时证据已验证。
（P00 现实：静态音乐托管 + API 壳 + 数据工厂批处理 + audiolla 代理为已运行；完整 Ear 链路为仓库代码。）
