## 1. 商业定位

**Moodify = AI 音频智能基础设施公司（AI Audio Intelligence Infrastructure Company）**

我们不与音乐平台竞争用户，也不与 DAW 工具竞争创作者。我们向整个音乐产业出售「听、评、测、用」的智能能力。

```
音乐产业价值链：

创作 ──→ 发行 ──→ 平台分发 ──→ 消费
         │            │
         ▼            ▼
    质量验证 ✅      目录运营 ✅     ← Moodify 切入点
    (QA)           (Rating)
         │            │
         ▼            ▼
      处理服务 ✅    商业授权 ✅
      (Master)      (Supply)
```

## 2. 收入模型（按产品）

### 2.1 Moodify QA — API 计费 + SaaS

| 模式 | 定价逻辑 | 目标客户 |
|------|---------|---------|
| API 按量计费 | 每分钟音频检测 × 单价 | 音乐平台、AI 音乐工具公司 |
| 批量检测 SaaS | 目录级订阅（按曲目量分档） | 发行商、厂牌、聚合器 |
| 企业定制 | 私有部署 + 定制标准 | 大型平台 |

**市场逻辑：** AI 音乐产量爆发 → 平台必须自动化验证 → QA 成为像 CDN 一样的基础设施采购。

### 2.2 Moodify Master — 按曲处理 + 订阅

| 模式 | 定价逻辑 | 目标客户 |
|------|---------|---------|
| 按曲处理 | 单曲母带处理费（低于人工 10-50 倍） | 独立音乐人 |
| 订阅 | 月度处理额度 | 高产量创作者、AI 音乐工作者 |
| 白标 | 处理能力嵌入第三方工具 | AI 音乐工具公司 |

**差异化卖点：** 证据链 + 身份保护 — 「可审计的 AI 母带」是专业用户信任的基础。

### 2.3 Moodify Rating — 评级服务 + 数据订阅

| 模式 | 定价逻辑 | 目标客户 |
|------|---------|---------|
| 目录评级项目 | 按目录规模一次性评级 | 版权基金、目录买方 |
| 评级 API 订阅 | 持续评级更新 | 流媒体平台、资产化平台 |
| 定制模型 | 按客户标准校准评分 | 大型版权方 |

**市场逻辑：** 音乐目录交易规模持续增长，估值高度依赖主观判断 — 机器可读的评级是资产化的前提。

### 2.4 Moodify Supply — 成交抽佣 + 企业 API

| 模式 | 定价逻辑 | 目标客户 |
|------|---------|---------|
| 匹配成交抽佣 | 每笔授权交易抽成 | 游戏公司、影视制作、广告代理 |
| 企业搜索 API | 按查询量订阅 | 内容平台、MCN |
| 分轨服务 | 按曲目分轨计费 | 二创、翻唱、混音市场 |

**市场逻辑：** 商业用乐采购高度依赖人脉和人工搜索 — 供给匹配层有网络效应潜力。

## 3. 增长飞轮

```
QA 服务客户 → 积累检测数据 → 评分模型更准（Rating）
     → 目录评级带来资产数据 → 供给匹配更准（Supply）
     → 交易数据回流 → 引擎全面增强 → QA 更强
```

**关键：** 四个产品共享同一个引擎，每个客户的使用都让整个平台更聪明 — 这是单体产品公司无法复制的壁垒。

## 4. 竞争格局

| 竞品方向 | 代表 | Moodify 差异 |
|---------|------|-------------|
| 自动母带 | LANDR、iZotope Ozone | 证据链 + 身份保护 + 可审计；面向产业而非仅创作者 |
| 音频检测 | ACR、音频指纹公司 | 不止识别（是什么），更评估（好不好、值多少） |
| AI 音乐生成 | Suno、Udio（潜在客户） | 我们是他们缺失的验证层，非竞争关系 |
| 音乐数据 | Chartmetric、Soundcharts | 外部行为数据 vs 我们的音频内在质量数据 |

**核心壁垒：**
1. 引擎共享 — 一个引擎服务四个市场，研发杠杆极高
2. 证据优先架构 — 产业级客户的信任基础（可审计、可回滚）
3. 数据飞轮 — 检测→评级→交易的闭环数据积累

## 5. 融资叙事框架

### 问题
AI 让音乐产量增长 100 倍，产业的验证、估值、匹配能力没有增长 — 「耳朵」成为瓶颈。

### 解决方案
Moodify Intelligence Platform：一个共享听觉智能引擎 + 四个产业产品模块（QA/Master/Rating/Supply）。

### 为什么是我们
- 已验证的测量技术（LUFS/频谱/动态范围，完整测试链）
- 证据优先架构（产业客户信任基础）
- 已上线产品（Android/Web）证明工程交付能力

### 市场规模（自上而下）
- 全球音乐产业 ~$400 亿+（IFPI）
- 音乐软件与服务市场 ~$100 亿+
- AI 生成音乐（新增市场）高速增长
- Moodify 切入：验证 + 处理 + 评级 + 授权匹配四个环节的基础设施采购

## 6. 原则约束

1. **不虚构能力** — 商业材料中的能力声明与 `docs/REPOSITORY_STATUS.md` 对齐；research 状态的能力明确标注
2. **产品各有名分** — QA/Master/Rating/Supply 独立品牌，不混淆为单一 "Moodify 功能"
3. **GPL 合规** — 核心开源（GPL v3），商业服务闭源 SaaS 层；API 服务不受 GPL 传染
4. **数据合规** — 不引入私有音频；客户数据按合同处理
