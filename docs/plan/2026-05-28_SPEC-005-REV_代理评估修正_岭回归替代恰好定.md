# SPEC-005-REV：代理评估修正 — 岭回归校正 T_EFFECTS

**时间**: 2026-05-28
**替换**: SPEC-005 原版
**修订原因**: 原版 5 探针恰好定拟合 25 参数，cv_error 默认 None 导致 J 从未被使用，12.5s 校准白跑。

---

## 0. 原版问题诊断

| 问题 | 根因 | 后果 |
|------|------|------|
| J 从未被使用 | 5 探针 → cv_error=None → use_j=False | 12.5s 校准被丢弃 |
| 恰好定过拟合 | 5 样本 → 25 参数, 零冗余 | J 完美拟合噪声 |
| T_EFFECTS vs J 无比较 | 两者从未在同一首歌上对比 | 不知道谁更准 |
| RAG 路径绕开校准 | RAG 成功不调搜索 | 校准覆盖率低 |

---

## 1. 修正方案核心

**不替代 T_EFFECTS，而是用岭回归校正它。**

```
原版: proxy_evaluate = J预测 (替代 T_EFFECTS)
修正: proxy_evaluate = T_EFFECTS预测 + α × J_ridge校正
```

当探针证实 T_EFFECTS 准确 → J_ridge ≈ 0 → 预测 ≈ T_EFFECTS（零开销被证实正确）。
当探针发现系统性偏差 → J_ridge 捕获偏差 → 预测 = T_EFFECTS + 修正。

### 1.1 岭回归

```
原版: J = argmin ||Y - XJ||²          → 恰好定, 过拟合噪声
修正: J = argmin ||Y - XJ||² + λ||J||² → 收缩估计, 偏向零

λ = 1.0 → 中等收缩强度
含义: "除非探针强烈证明 T_EFFECTS 错了, 否则相信 T_EFFECTS"
```

### 1.2 预测公式

```
Δws_pred = Δws_TE(s) + α × J_ridge @ (s - 0.5)

α = blend_weight(condition_number):
  cond < 20  → α = 0.8  (探针可信, 大幅校正)
  cond < 50  → α = 0.5  (探针可参考, 适度校正)
  cond < 100 → α = 0.2  (探针勉强, 保守校正)
  cond ≥ 100 → α = 0.0  (探针不可信, 纯 T_EFFECTS)

Δws_TE(s) = T_EFFECTS 预估的 5D 变化 (apply_chain_transfer)
```

### 1.3 关键性质

```
性质 1: 3 个探针就够。岭回归不需要过定系统。λ 提供虚拟先验。
性质 2: 不需要 cv_error。condition_number 已足够判断探针质量。
性质 3: 当探针 = T_EFFECTS 预测时，J_ridge ≈ 0，α 无关。无校正 = T_EFFECTS 被验证。
性质 4: 校准失败时 α=0，纯 T_EFFECTS 回退。零风险。
```

## 2. 修改文件

### 2.1 `optimizer/calibrate.py` — 加 ridge 参数

在 `calibrate()` 函数签名加 `ridge_lambda: float = 1.0`，修改最小二乘步骤：

```python
# 原版:
J_T = np.linalg.lstsq(X, Y, rcond=None)[0]

# 修正为 (岭回归):
XTX = X.T @ X
XTX_ridge = XTX + ridge_lambda * np.eye(5)
J_T = np.linalg.solve(XTX_ridge, X.T @ Y)
```

返回值增加:
```python
"ridge_lambda": ridge_lambda,
```

### 2.2 `optimizer/search.py` — 重写 `proxy_evaluate`

```python
def proxy_evaluate(
    strength_vector: dict[str, float],
    ws_raw: np.ndarray,              # (5,)
    target: np.ndarray,              # (5,)
    dist_before: float,
    emotion_code: str = "GA",
    J: np.ndarray | None = None,     # (5,5) ridge Jacobian
    condition_number: float | None = None,
) -> float:
    """T_EFFECTS 为基础，岭回归 J 为校正。

    公式: Δws = Δws_TE + α × J @ (s - 0.5)
    α 由 condition_number 决定。
    """
    # Step 1: T_EFFECTS 基准预测 (始终计算)
    eds_te = _proxy_te_base(strength_vector, ws_raw, target, dist_before, emotion_code)

    # Step 2: 判断是否需要校正
    if J is None or condition_number is None:
        return eds_te

    if condition_number < 20:
        alpha = 0.8
    elif condition_number < 50:
        alpha = 0.5
    elif condition_number < 100:
        alpha = 0.2
    else:
        return eds_te  # 探针不可信, 纯 T_EFFECTS

    # Step 3: 岭回归校正
    ws_te = _get_te_wave_state(strength_vector, ws_raw, emotion_code)
    sv_arr = np.array([strength_vector.get(d, 0.5) for d in CHAIN_ORDER])
    delta_correction = alpha * (J @ (sv_arr - 0.5))
    ws_corrected = ws_te + delta_correction
    dist_corrected = float(np.linalg.norm(ws_corrected - target))
    eds_corrected = 100.0 * (1.0 - dist_corrected / max(dist_before, 1e-8))

    return float(np.clip(eds_corrected, -100.0, 100.0))
```

新增辅助函数:

```python
def _get_te_wave_state(
    strength_vector: dict[str, float],
    ws_raw: np.ndarray,
    emotion_code: str,
) -> np.ndarray:
    """T_EFFECTS 状态转移后的 5D 向量 (不计算评分, 只返回向量)"""
    from moodify.orchestration.state_transfer import StateTransferEngine, WaveStateProcess

    ws_proc = WaveStateProcess(
        E=float(ws_raw[0]), D=float(ws_raw[1]),
        S=float(ws_raw[2]), T=float(ws_raw[3]), H=float(ws_raw[4]),
    )
    engine = StateTransferEngine()
    chain_strengths = [strength_vector.get(t, 0.5) for t in CHAIN_ORDER]
    ws_out, _ = engine.apply_chain_transfer(ws_proc, CHAIN_ORDER, chain_strengths, emotion_code)
    return ws_out.to_array()


def _proxy_te_base(
    strength_vector: dict[str, float],
    ws_raw: np.ndarray,
    target: np.ndarray,
    dist_before: float,
    emotion_code: str,
) -> float:
    """纯 T_EFFECTS 评分 (无 J 校正, 无惩罚项)"""
    ws_te = _get_te_wave_state(strength_vector, ws_raw, emotion_code)
    dist_after = float(np.linalg.norm(ws_te - target))
    eds = 100.0 * (1.0 - dist_after / max(dist_before, 1e-8))
    return float(np.clip(eds, -100.0, 100.0))
```

删除: `_proxy_evaluate_legacy()` — 逻辑拆分到 `_get_te_wave_state` + `_proxy_te_base`。

### 2.3 `optimizer/search.py` — 修改 `search_optimal_strengths`

在原 LHS 采样之后、评估循环之前，插入校准逻辑：

```python
# 校准（如果提供了 audio）
J = None
cond_num = None
ws_raw_arr = None
target_arr = None
dist_before = None

if audio is not None:
    try:
        from moodify.optimizer.calibrate import calibrate
        cal = calibrate(diagnosis, audio, sr, emotion_code, n_probes=5)
        J = cal["J"]
        cond_num = cal["condition_number"]
        ws_raw_arr = cal["ws_raw"]
        target_arr = cal["target"]
        dist_before = float(np.linalg.norm(ws_raw_arr - target_arr))
    except Exception:
        pass

# T_EFFECTS 回退路径
if ws_raw_arr is None:
    from moodify.orchestration.state_transfer import StateTransferEngine
    from moodify.knowledge.emotion_targets import get_ideal_process_vector
    ws_proc = StateTransferEngine.diagnostic_to_process(diagnosis)
    ws_raw_arr = ws_proc.to_array()
    target_arr = get_ideal_process_vector(emotion_code)
    dist_before = float(np.linalg.norm(ws_raw_arr - target_arr))

# 评估循环 (签名简化: 去掉 sigma_inv, cv_error)
for vec in vectors:
    score = proxy_evaluate(
        vec, ws_raw_arr, target_arr, dist_before,
        emotion_code=emotion_code,
        J=J, condition_number=cond_num,
    )
    scored.append((vec, score))
```

## 4. 与原版的关键差异

| | SPEC-005 原版 | SPEC-005-REV |
|---|---|---|
| 拟合方法 | 最小二乘 (恰好定) | 岭回归 (收缩估计) |
| 5 探针可用性 | 不可用 (cv_error=None) | 可用 (condition_number) |
| 与 T_EFFECTS 关系 | 替代 | 校正 |
| J=0 时行为 | 预测归零 (错误) | 预测 = T_EFFECTS (正确) |
| 3 探针可行 | 否 (欠定) | 是 (λ 提供正则) |
| 惩罚项 | 无 (被删除) | 无 (J 校正自然包含约束) |
| 信任门控 | cv_error + cond | cond only |
