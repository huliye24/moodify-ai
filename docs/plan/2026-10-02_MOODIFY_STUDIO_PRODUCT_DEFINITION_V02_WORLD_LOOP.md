## 1. 一句话定位（v0.2，取代 v0.1 §1）

**Moodify Studio = 听觉的创意沙盒**：一首歌进入 Moodify 就成为一个持久世界；专业人士把审美意图说给 Mood 编译器，编译成算子链，渲染出可试听、可复现的新版本；版本共存不排名，不同审美长出不同创意。测量核心是世界的物理引擎——永不说谎。

壳形态仍是 PyCharm 式 IDE 骨架（v0.1 §2 不变），变的是**行为模式**：从流水线到循环。

## 2. 行为模型：流水线 → 世界循环

| | v0.1 及之前（流水线） | v0.2（世界循环） |
|---|---|---|
| 隐喻 | 检测流水线：歌进去，报告出来 | 沙盒世界：歌是存档，人在里面建 |
| 步骤 | 选歌→检测→数据→方案（单向，有终点） | 观察→意图→编译→渲染→对比（循环，无终点） |
| 检测的地位 | 每次流程的第一步 | **只发生一次**：选歌=创建世界（物理引擎初始化） |
| 产物 | report.json + plan.md（终点） | 版本树（每个版本=一次创造，可分叉） |
| AI 的角色 | 答案机（一次给最佳） | 编译器（每轮产出一个方向的一个版本） |
| 用户的角色 | 看报告的人 | 反复使用的创作者 |
| 第二次进来的事 | 没有 | 继续：换审美、分叉、对比、精修 |

**核心循环（game loop）：**

```
进入世界 ──► 观察（图表优先）
   ▲             │
   │             ▼
分叉/保留 ◄── 对比（A/B 试听 + delta 只描述不评级）
   │             ▲
   └── 渲染 ◄─ 编译（意图 → 算子链）
```

"不是一下子就得到最佳"由结构保证：循环没有"最佳"这个终点，只有"你的耳朵认不认"。

## 3. 对象模型

| 对象 | 定义 | 落地 |
|---|---|---|
| 世界（World） | 一首歌的全部上下文 | case 目录（沿用 `~/.moodify/cases/case_*`），打开后**没有关闭**，只有切换 |
| 创建世界 | 选歌 + 一次完整检测 | 现有 `moodify.release_cli demo` 链路（report/measurements/charts） |
| 意图（Intent） | 审美方向，人话 | 如"70 年代暖声""夜店母带"；存 `intent.md` |
| 算子链（Chain） | 可复现配方 | 编译器产出，映射到 processing 标准算子 |
| 版本（Version） | 一次创造的产物 | `versions/vNNN_<意图名>/`：`intent.md` + `chain.json` + 渲染音频 + `evidence.json`（前后指标 delta） |
| 试听 | 壳内 A/B | 任意两版本对切，不出壳 |
| 账本 | 贡献记录 | 每次渲染落 `contributions.jsonl`（复用 `moodify.contribution` 域） |

**版本不排名**：版本树没有排行榜，delta 只描述不评级（Layer B 既定原则）；算法判断只在专业者显式召唤 A/B Judge 时出现。

## 4. 壳改动清单（W4）

1. **删除"关闭当前 case"（✕）**：case 打开后无关闭态；空态只在首次启动出现。
2. **历史档案 → "世界"**：双击 = 切换世界。
3. **底部 = 意图命令条**：编译器输入常驻底部（MC 聊天栏位）；终端收缩为可折叠工程面；删除"在此目录打开 Codex"按钮——**AI 只留编译器一扇门**（裁决 4"共存"修订为"终端只做工程面"）。
4. **图表优先落地**：进入世界默认视图 = 观察（图表），数据表降为二级。
5. **A/B 试听条**：常驻，任选两版本对切（界面无出口）。
6. **第四图标 = 贡献**：本地账本面板（W3 面板位）。
7. **渲染动作**：命令条产出的算子链经显式"渲染"按钮 → 核心执行 → 新版本入树（P0 边界见 §5）。

## 5. 渲染边界（新不变量，取代"DRAFT_PLAN_NOT_EXECUTED"）

- **方案是草稿，渲染是显式动作，版本是产物。** 编译器永不自动执行；每次渲染由人按下。
- **身份门保留否决权**：任何算子链先过 Identity Guard；被否决的链不得渲染，除非显式旁路并如实记录（P06 既有语义）。
- **硬门自动执行**：时长保持 / 声道保持 / 响度预算（golden pipeline 既有 `_HARD_GATES`），失败即版本标记 FAILED，不入可试听树。
- **源不可变**：世界创建时源冻结（sha256），一切版本从源派生；回滚 = 切回 SOURCE，永不覆盖。
- **诚实标注不解除**：阈值 0/16 calibrated（DEFAULT_UNCALIBRATED）照标；版本 delta 只描述不评级；L3/L4/L5 判断不承诺。

## 6. 实现锚点（全部已存在，2026-10-02 核实）

| 能力 | 模块 | 来源 |
|---|---|---|
| 世界创建（检测+报告+图表） | `moodify.release_cli demo` + `ui.chart_export` | 壳现用 |
| 渲染引擎（源冻结→时代诊断→A/B/C 目标→渲染→硬门→盲听套件） | `reconstruction.pipeline.run_golden_pipeline` | 经典重建 P06 |
| 算子层 | `processing.operators` / `pedalboard_chain` / `spectral_chain` | Mix Graph v0.1 等 |
| 身份否决 | `identity_guard` + `intervention.identity_gate` | P05 / 补丁包 71 |
| 作业语义（幂等/owner-only/显式执行） | `reconstruction_job` | P08 |
| 算法评审（显式召唤） | `evaluation`（pairwise A/B Judge） | 补丁包 09 |
| 贡献账本 | `moodify.contribution`（状态机/证据/评分器/CLI，39/39 绿） | Contribution 域 Gate3 |
| AI 编译器内核 | Codex app-server + DeepSeek（真轮次已验证） | W2 |

**W4/W5 是"接线"不是"造引擎"**：把已验证的核心能力接进壳的循环里。

- **W4 壳改造（纯壳）**：§4 第 1–4 项（✕ 删除/世界/意图命令条/图表优先）。验收：启动冒烟 + 打开→循环四步可达 + AI 单门。
- **W5 渲染循环（接线）**：§4 第 5、7 项 + §5 边界全部落地。验收：一个真实 case 完整跑通 意图→编译→渲染→试听→版本入树；硬门失败路径可见；身份门否决路径可见。

## 10. 遗留 bug（本定义核实中发现，已随 W4 修复）

终端抽屉首启失败：`~/.moodify/cases` 不存在时 `pty:create` 以无效 cwd spawn → node-pty 错误 267，抽屉白板。修法：创建时 `mkdirSync(CASES_ROOT, {recursive:true})`，cwd 兜底 `os.homedir()`。

## 11. W4 修正案（2026-10-02 深夜，人类实测反馈）

人类指令要点："检测完成后数据和图表不在侧边栏，在上面标签页直接看到，不用下滑，处理完是空白；数据、图表、音频波谱像 Audacity；第三个标签页是后处理；下方对话框不需要引导文字，就是写文字，DeepSeek API 回答以及操作；这是全新的产品定义和形式，不同于过去的修音软件——**打通音乐生产力**"。

落地裁决：

| # | 裁决点 | 裁决 |
|---|---|---|
| 10 | 视图承载 | **顶部标签页**取代侧栏视图图标：`数据 / 图表·波谱 / 后处理` 三页；进入世界直接落在「图表·波谱」，首屏有内容 |
| 11 | 波形 | **Audacity 式波形**：壳内 Web Audio 解码源音频 → canvas 峰值包络（L/R 双声道 + 时间标尺）。零核心改动、零新依赖；源路径经 `source_path.json` 随 case 记录（report.json 只有 name/sha256） |
| 12 | 意图输入 | **去引导语**：输入框无占位文字，直接写；编译器回答与操作（"操作"= W5 渲染接线的入口语义） |
| 13 | 北极星 | **打通音乐生产力**：Moodify 不是修音软件，是音乐生产力工具——记录为本定义的目标语义，W5（渲染）为其第一段落地 |
