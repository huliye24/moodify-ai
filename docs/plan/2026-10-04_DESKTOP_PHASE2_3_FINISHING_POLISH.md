# Moodify Desktop Phase 2.3 — 完成时刻与作品留存打磨

**Date:** 2026-10-04  
**Status:** IMPLEMENTATION BRIEF  
**Owner / final acceptance:** Codex（主控）  
**Implementation delegate:** DeepSeek / Claude Code  
**Depends on:** Phase 2.2 A/B Review Workspace  
**CANON_CHANGE:** NO — 不改变声音流程、选择权威或导出契约  
**MIP_REQUIRED:** NO  

## 0. 任务原则

不要在产品里解释美学，不展示哲学概念，不加入“关于设计”的文字。

```text
不说花为什么美。
让花香自己表达。
```

本任务只通过界面、声音、时间、留痕和再次打开时的体验，让一首歌在“处理完成”之后成为一个
用户愿意保留的东西。

不得把这项工作做成：

- 品牌宣言页面；
- 教程或理念弹窗；
- 更多技术指标；
- 华丽但与作品无关的动画；
- 任务完成庆祝页；
- 社交分享、云端收藏或成就系统。

## 1. 唯一产品结果

当用户试听原版/A/B并作出选择后，Moodify 不应只把“导出”按钮点亮。界面应自然进入一个安静、
完整、可停留的作品状态：

```text
歌曲标题
被选中的版本
完整波形印记
完成日期
一句可选的私人文字

▶ 从头听
导出音频
保存作品卡
```

用户下次再次打开这首歌时，仍能看见这份完成状态、当时的选择和留下的话。

## 3. 完成状态的进入方式

### 3.1 触发条件

仅当以下事实同时成立时展示作品完成层：

```text
有效 pair
A/B 两侧候选完整
真实 recheck 完成
有效人工 decision = A | B | ORIGINAL
```

必须使用现有 pipeline / tuning 推导，不新增 `is_complete=true` 权威字段。

### 3.2 进入动作

人工选择成功后：

- 不弹出大型庆祝模态框；
- 不播放掌声、提示音或自动音乐；
- REVIEW 内容缓慢收束到完成层，约 240–400 ms；
- 被选择版本的名称稳定落在标题下方；
- 页面焦点落到“从头听”，但不自动播放；
- 用户仍可返回 A/B REVIEW 改选。

动画必须服从 `prefers-reduced-motion`。减少动画时直接切换，不影响功能。

## 4. 完成层设计

### 4.1 首屏只保留作品

完成层首屏不得出现 LUFS 大表、调试状态、pair_id、schema、hash、Core 命令或能力说明。

首屏结构：

```text
┌──────────────────────────────────────────┐
│                                          │
│             歌曲标题                      │
│          A（保守）· 快速完成              │
│                                          │
│       ───── 完整波形印记 ─────             │
│                                          │
│             2026.10.04                   │
│                                          │
│              ▶ 从头听                     │
│                                          │
│      导出音频       保存作品卡              │
│                                          │
└──────────────────────────────────────────┘
```

“快速完成”只作为小型事实标签，不作为主标题。若保留原版，显示“保留原版”，不伪装成处理版本。

### 4.2 波形印记

从最终选择的真实音频生成一个只读、确定性的波形视觉：

- 使用现有解码结果或播放器 waveform 数据；
- 相同音频必须得到相同形状；
- 不生成随机 AI 封面；
- 不上传音频；
- 不修改声音；
- 可做轻微渐变、留白和细线层次；
- 不显示时间刻度、网格或工程游标；
- 波形印记不是分析证据，不进入 Core。

它应像作品的指纹，而不是 DAW 截图。

### 4.3 颜色

颜色从 Moodify 现有品牌色和最终选择推导，保持稳定：

```text
ORIGINAL  中性灰蓝
A         蓝紫
B         暖橙
```

背景保持克制、低对比、可长时间观看。禁止霓虹光污染、彩纸、奖杯、烟花、粒子爆炸。

颜色不能成为区分选择的唯一方式；版本名称始终显示。

### 4.4 空间与字体

- 使用明显留白，不把所有可用空间塞满；
- 标题是页面视觉中心；
- 技术信息退到“制作详情”；
- 正文不超过两种主要字号层级；
- 控件数量保持最少；
- 不使用拟物唱片、黑胶、磁带等与真实作品无关的装饰模板。

## 5. 一句私人文字

完成层提供一个轻量、可选的入口：

```text
留一句话
```

点击后出现单行或短文本输入，placeholder 只写：

```text
写给这首歌
```

规则：

- 完全可选，不阻止导出；
- 最多 280 个 Unicode 字符；
- 支持换行但最多 4 行；
- 默认不让 AI生成、不提示范文；
- 不分析文字，不用于推荐；
- 本地保存；
- 可编辑、可清空；
- 清空必须是普通编辑行为，不设计危险确认弹窗；
- 作品卡默认包含这句话；用户可在保存作品卡前取消包含。

产品界面不解释这句话的意义。

## 6. 非权威留存记录

允许新增：

```text
<case>/studio/keepsake.json
```

建议 schema：

```json
{
  "schema": "moodify.studio.keepsake/0.1",
  "case_id": "...",
  "decision_request_id": "...",
  "selected": "A | B | ORIGINAL",
  "completed_at": "ISO-8601",
  "inscription": "",
  "updated_at": "ISO-8601"
}
```

纪律：

- 这是表现层留存记录，不是完成状态权威；
- `selected` 必须从当前有效 decision 投影，不得反向解锁导出；
- decision 改变时，记录更新为新的选择，文字保留；
- decision 失效时，完成层消失，但文字不删除；
- 使用临时文件 + 原子替换写入；
- 只允许当前 case 内写入；
- 不保存音频字节、图片 base64、完整 report 或 hash 大表；
- 读取失败时不影响声音流程，显示为空白留存状态并记录可诊断错误。

若实现代理发现已有合适的非权威 metadata 文件可扩展，可以复用，但必须说明兼容与迁移；不得把
keepsake 塞进 `decisions.jsonl`。

## 7. 从头听

完成层的核心动作是：

```text
▶ 从头听
```

行为：

- 加载最终选择的真实音频；
- 播放位置回到 0；
- 明确显示当前播放版本；
- 使用 Phase 2.2 的同一播放器和 AudioContext；
- 不循环播放；
- 不自动播放；
- 播放中减少不必要控件，只保留播放/暂停、时间、音量和退出聆听；
- 歌曲结束后保持安静，不自动跳到下一首，不弹推荐。

允许用户进入“安静聆听”视图：

- 隐去制作流程、指标和侧栏；
- 保留标题、版本、波形印记和 transport；
- `Esc` 或“返回制作详情”退出；
- 不进入全屏系统模式，不抢占桌面；
- 不阻止用户正常切换窗口。

## 8. 作品卡

### 8.1 保存动作

提供：

```text
保存作品卡
```

生成一张本地 PNG，内容只包括：

- Moodify 小型标识；
- 歌曲标题；
- 最终选择（A / B / 保留原版）；
- 波形印记；
- 完成日期；
- 可选的私人文字。

不包含：

- 技术评分；
- “AI 增强”营销语；
- LUFS、频谱或参数表；
- 文件绝对路径；
- case_id、pair_id、hash；
- 用户账号、设备信息；
- 二维码、链接或社交平台按钮。

### 8.2 输出规则

- 用户点击保存后才打开系统保存对话框；
- 默认文件名：`<歌曲名> — Moodify.png`，需清理非法字符；
- 用户取消保存不算失败；
- PNG 建议 1600×1000 或等比例高分辨率；
- 导出结果需在常见图片查看器中清晰；
- 使用确定性的 renderer/canvas 绘制，不调用生成式图像服务；
- 不把作品卡自动写入仓库或 case；
- 不自动上传或分享。

## 9. 再次打开

用户重新打开已完成 case 时：

- 默认进入完成层，而不是回到技术流程顶部；
- 标题、选择、波形印记、完成日期和私人文字恢复；
- 明确提供“查看制作详情”；
- 若 decision 已失效，回到真实 REVIEW/阻断状态，不显示假完成；
- 若最终音频被移动或损坏，保留文字但显示“音频不可用”，不得用其他版本替代；
- 不自动播放。

“重新完成”或新建 pair 不应覆盖旧 pair 与账本；当前有效选择仍由现有 tuning 规则决定。

## 10. 制作详情的退场方式

完成不等于删除技术证据。所有证据仍可通过：

```text
查看制作详情
```

返回 Phase 2.2 A/B REVIEW：

- 原版/A/B 播放；
- 频谱与图表；
- recheck；
- Mix Graph 与参数；
- 改选；
- 导出。

完成层是第一视图，制作详情是可回到的第二层。不得复制第二份数据与播放器逻辑。

## 11. 微交互打磨

以下细节必须统一：

- hover 只做轻微明度/边框变化，不浮夸位移；
- 按下按钮有明确但短促的反馈；
- 保存成功只显示一条安静的状态文字，例如 `作品卡已保存`；
- 错误就地显示，不弹连续 toast；
- 长标题正确截断，同时可查看完整标题；
- 中文、英文、法文重音字符均正确显示；
- 窗口缩放后波形印记保持比例；
- 800 px 以上宽度不出现横向滚动；
- 键盘焦点清晰；
- `prefers-reduced-motion` 完整生效。

产品文案保持短：

```text
从头听
暂停
留一句话
保存作品卡
导出音频
查看制作详情
返回作品
```

不要加入解释性副标题和理念句。

## 13. 必须新增的测试

### 13.1 完成门禁

- 无 decision 时不显示完成层；
- 手写假 decision 不显示完成层；
- A/B/recheck 被删除后完成层立即失效；
- A、B、ORIGINAL 三个真实出口都可进入完成层；
- keepsake 不能解锁 CHOSEN 或导出。

### 13.2 留存记录

- inscription 长度与 Unicode 正确；
- 原子写入，不留半文件；
- 路径严格限制在当前 case；
- decision 改变时 selected 更新、文字保留；
- decision 失效时不删除文字；
- 损坏 JSON 不阻断声音流程；
- 重启后完整恢复。

### 13.3 播放

- “从头听”播放当前有效选择的真实音频；
- 选择 ORIGINAL 时绝不播放 A/B；
- 不自动播放；
- 不创建第二个 AudioContext；
- 曲终不自动跳歌；
- 音频缺失时不偷偷回退到别的版本。

### 13.4 作品卡

- PNG 尺寸正确且可解码；
- 标题、选择、日期、波形印记正确；
- inscription 可包含/排除；
- 不泄露绝对路径、case_id、pair_id 或 hash；
- 用户取消保存不写文件；
- 文件名非法字符被安全处理；
- 相同输入产生相同波形印记。

### 13.5 Renderer contract

- 所有新 DOM id、preload bridge、IPC 和事件绑定守恒；
- 完成层与制作详情可双向进入；
- reduced-motion 分支存在；
- 关键动作可通过键盘完成；
- 窗口缩放不产生横向溢出。

### 13.6 回归

```text
cd moodify-desktop && npm test
python scripts/check_repo_structure.py
python -m ruff check moodify-core-package/src moodify-core-package/tests
```

## 14. 人工验收脚本

使用一首真实歌曲完成 A/B 复检并选择一个出口：

1. 选择成功后自然进入完成层，没有庆祝弹窗；
2. 第一眼只看到作品标题、版本、波形印记、日期与核心动作；
3. 点击“从头听”，确认播放的就是最终选择；
4. 歌曲播放结束后界面保持安静；
5. 写一句包含中文和重音字符的文字，重启后仍存在；
6. 保存作品卡，检查 PNG 清晰且没有技术隐私字段；
7. 进入“查看制作详情”，A/B evidence 仍完整；
8. 改选另一个版本，返回作品时版本更新、私人文字保留；
9. 重新打开 case，默认进入完成层；
10. 模拟最终音频缺失，确认不播放错误版本。

交付报告附完成层、安静聆听和作品卡截图；不得提交私人音频或用户写下的私人文字。

## 15. Definition of Done

```text
完成之后不再只剩一个可点击的导出按钮
作品本身成为完成页中心
用户可以从头安静听完最终选择
用户可以留下一句本地私人文字
用户可以保存一张克制、确定性的作品卡
重新打开时完成状态与文字仍存在
制作证据始终可回看
所有状态都由现有 decision 与磁盘事实支撑
没有哲学说明、营销口号或过度动画
没有第二套声音、播放器、状态机或数据权威
全部自动化与人工验收通过
```
