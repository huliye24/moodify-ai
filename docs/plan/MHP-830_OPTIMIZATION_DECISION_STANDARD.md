**Status**: done

## Goal

Standardize the format and lifecycle of optimization decisions so they are consistent across loops, comparable across nights, and auditable.

## Decision Object Standard

### Required Fields

```json
{
  "decision_id": "string — unique per decision, format: {run_id}:{loop}:{task_id_suffix}",
  "run_id": "string — source run identifier",
  "loop": "enum[runtime_reliability, scoring_calibration, craft_preset_selection, operator_report]",
  "severity": "enum[low, medium, high]",
  "status": "enum[open, in_progress, resolved, dismissed, superseded]",
  "reason": "string — max 180 chars",
  "action": "string — max 220 chars, one concrete next step",
  "owner_subsystem": "string — which module owns execution",
  "needs_human_review": "boolean",
  "created_at": "ISO-8601",
  "resolved_at": "ISO-8601 or null",
  "resolution_note": "string or null — how it was resolved"
}
```

### Status Flow

```text
open → in_progress → resolved
  ↓                    ↓
dismissed         superseded
```

### Decision Lifecycle

1. **open**: Generated by the recommendation engine. Awaiting action.
2. **in_progress**: Someone (human or AI) is working on it.
3. **resolved**: Action completed. Verified by next night's run.
4. **dismissed**: Reviewed and intentionally not acted upon (with reason).
5. **superseded**: Replaced by a newer decision for the same signal.

### Severity Definitions (Standardized)

| Severity | Definition | Response Time | Example |
|----------|-----------|---------------|---------|
| **high** | Blocks night run or causes systematic errors | Fix before next run | Fatal error, scoring gap > 50 |
| **medium** | Degrades quality but doesn't block | Fix within 3 nights | Single flag, moderate disagreement |
| **low** | Minor observation, no immediate action | Log and monitor | Near-zero delta disagreement |

### Cross-Night Tracking

Each decision should be stored in a JSONL file:

```
reports/data_loop/decisions.jsonl
```

Format: one JSON object per line, with `decision_id` as the unique key.

Query examples:

```bash
# Open high-severity decisions
grep '"severity":"high"' reports/data_loop/decisions.jsonl | grep '"status":"open"'

# Decisions for a specific loop
grep '"loop":"scoring_calibration"' reports/data_loop/decisions.jsonl

# Resolved rate this week
echo "scale=2; $(grep -c '"status":"resolved"' reports/data_loop/decisions.jsonl) / $(wc -l < reports/data_loop/decisions.jsonl)" | bc
```
