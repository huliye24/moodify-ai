# MHP-846: MAP-Chain Interface Contract

**Status**: done
**Direction**: ECHAIN-MOODIFY-MAP-CHAIN-015 / NEM-MOODIFY-MAP-PROBE-045 / Probe Plan-6A: Contract Definition / E2
**Depends on**: MHP-845
**Protocol**: AWJ Stack + E-Chain 54

## Context

MAP-Chain needs stable interfaces before deeper scan, diagnosis, MRS, report, and delivery upgrades can be assigned to Workers. Without a contract, Worker output will drift.

## Goal

Define the canonical v0.1 MAP objects:

- `InputAudio`
- `ScanResult`
- `FeatureAnalysis`
- `DiagnosisResult`
- `ProcessPlan`
- `ValidationResult`
- `ReportBundle`
- `DeliveryPackage`

## Acceptance Criteria

- Contract includes required and optional fields for all seven MAP layers.
- Schema validates a v01 JSON report generated by `v01-process`.
- Contract distinguishes `mrs_proxy_v01` from calibrated MRS.
- Contract defines backwards-compatibility policy for CLI/API payloads.
