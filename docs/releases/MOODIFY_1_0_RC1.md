# Moodify 1.0.0-rc.1 — The Ear of AI

Moodify asks: **Can machines learn to hear?** The RC provides one default path: import audio, create a stable case, represent sound, produce bounded evidence-backed findings, save the Auditory Report, and reopen it.

Included: canonical contracts; auditory scanning; confidence/version/evidence judgments; explicit UNKNOWN/PARTIAL reports; JSON CLI; auditory-only API; Android Home / Analyze / Library / Profile shell.

Requirements: Python 3.10–3.12, FFmpeg/ffprobe, and JDK 17+ for Android.

Known limitations: artistic approval requires a human; unvalidated musical structure remains UNKNOWN; device instrumentation and owned-audio validation are pending; marketplace, CWC, feed, publishing and social features are excluded.
