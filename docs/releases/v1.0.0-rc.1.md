# Moodify 1.0 — Data Foundation (v1.0.0-rc.1) — Release Notes

**Target:** 2026-08-31
**Status:** DRAFT — final commit, freeze manifest and tag land at Gate 6 close

## What this release is

A frozen, evidence-first **data-production framework** for auditory intelligence:
a real song enters, a reproducible, inspectable, versioned Auditory Production
Case leaves. September runs this loop without architectural change.

## Scope

- Standards-backed measurement (BS.1770-4 integrated loudness, EBU 3342 LRA,
  true-peak, clipping, DC, spectral/band descriptors) under frozen scan
  profile `MFY-WSE-SCAN-PROFILE-001`.
- Diagnosis-derived A/B/C intervention plans (A=conservative, B=balanced,
  C=exploratory) and reproducible DSP candidates.
- Deterministic **algorithmic review** replacing human blind ranking
  (decision 2026-08-11): SOURCE/A/B/C ranked by frozen formula
  `MFY-ALGO-REVIEW-FORMULA-001`; no listening step anywhere in the loop.
- 24/7 unattended data node (2C2G, single worker, queue survives restarts,
  resource deferral, failure injection tested 10/10 matrix: 8 PASS + 2 FINDING fixed).
- Deterministic reference audio suite (10 fixtures, hashes, expected values)
  and cross-machine repeatability (52/52 metrics identical, 2026-08-11).
- Versioned Data Protocol v1, evidence manifests with artifact hashes,
  deterministic pairwise training rows.

## Limitations (explicit)

- Metrics are trustworthy only under the frozen profile; any profile change is
  a new version with explicit data separation (freeze protocol §1.4).
- The algorithmic reviewer is a deterministic technical ranking, **not** a
  claim about artistic quality; subjective/aesthetic claims are out of scope.
- Musical-structure analysis (MSE) and research/experimental modules are not
  part of the frozen surface.
- Cross-machine determinism covers the before-scan path; candidate processing
  was not separately cross-injected on both machines.
- The 10-song pilot ran on operator-owned tracks; no third-party audio is
  committed. The public golden case uses a synthetic fixture.
