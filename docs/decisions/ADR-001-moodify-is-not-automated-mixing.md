# ADR-001｜Moodify is not automated mixing

- Status: Accepted
- Date: 2026-07-31

## Context
“自动混音”把项目拉向替代人工操作、低价和一键输出，不能表达结构恢复、证据链和生产资产化。

## Decision
Moodify 定位为 AI 生成音乐后生成处理、质量分析、结构恢复和资产化基础设施；人工保留艺术方向和最终责任。

## Alternatives
自动混音 SaaS；插件套件；在线母带；通用 AI 音乐平台。

## Consequences
减少消费者功能；增加案例、证据、结构和基准投入；不能在无实验时宣称超过人工。
