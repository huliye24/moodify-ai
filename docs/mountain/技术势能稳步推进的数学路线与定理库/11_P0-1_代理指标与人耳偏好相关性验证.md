## 1. 实验设计

### 1.1 素材

```
10 首 AI 生成音乐, 覆盖:
  - 3 首 Suno v4 生成
  - 3 首 Udio 生成
  - 4 首 Suno v3 生成

风格分布:
  - 3 首钢琴/器乐
  - 4 首有人声的流行/民谣
  - 2 首电子/氛围
  - 1 首摇滚/重型

缺陷覆盖:
  确保 17 种缺陷类型中至少有 10 种出现
```

### 1.2 版本生成

每首歌生成 5 个处理版本:

```
v1: get_recommended_params(emotion) — 工艺卡预设 (baseline)
v2: search_optimal_strengths top-1
v3: search_optimal_strengths top-3 中的另一个
v4: LLM 推荐 (如果 API 可用)
v5: 手动极端参数 (测试代理指标的边界行为)
```

### 1.3 评价协议

```
听众: 5-10 人
设备: 监听耳机或监听音箱 (标准化)
协议: A/B 强制选择 + 置信度 (1-5)

每对比较:
  - 播放 A (2-3 秒), 播放 B (2-3 秒)
  - 问题: "哪个版本更好？" (A / B / 无差异)
  - 如果是 A 或 B: "确定程度？" (1=不确定, 5=非常确定)

每位听众: 50-100 次比较 (控制在 30 分钟内)
```

## 2. 数据分析

### 2.1 Bradley-Terry 建模

```python
from sklearn.linear_model import LogisticRegression

# 每对比较产生一个训练样本
# A beats B → 标签=1, 特征=[A的特征 - B的特征]
# B beats A → 标签=0

model = LogisticRegression()
model.fit(X_pairwise, y_preference)
theta = model.coef_[0]  # 每个版本的潜在质量
```

### 2.2 相关性计算

```python
from scipy.stats import spearmanr, kendalltau

proxy_scores = [EDSR_proxy(v) for v in versions]
true_scores = theta  # Bradley-Terry 估计的潜在质量

rho, p_rho = spearmanr(proxy_scores, true_scores)
tau, p_tau = kendalltau(proxy_scores, true_scores)

print(f"Spearman ρ = {rho:.3f} (p = {p_rho:.3f})")
print(f"Kendall τ = {tau:.3f} (p = {p_tau:.3f})")
```

### 2.3 决策矩阵

```
ρ ≥ 0.5  → 代理可用于搜索排序 (主信号)
0.3 ≤ ρ < 0.5 → 代理只能用于粗筛 (top-50, 不用于 top-3)
ρ < 0.3 → 代理不可用于排序, 需重构指标
```

### 2.4 失败样本分析

```
对每首测试曲, 比较 top-1(proxy) vs top-1(human):
  如果一致 → 成功
  如果不一致 → 失败样本, 记录:
    - 代理为什么高估了版本 A？
    - 人耳为什么偏好版本 B？
    - 诊断快照
    - 参数差异
```

## 3. 修正策略

### 3.1 如果 ρ ∈ [0.3, 0.5)：线性校准

```python
from sklearn.linear_model import LinearRegression

reg = LinearRegression()
reg.fit(proxy_scores.reshape(-1, 1), true_scores)
proxy_calibrated = reg.predict(proxy_scores.reshape(-1, 1))
```

### 3.2 如果 ρ < 0.3：指标重构

```
重构方向:
  1. 增加维度权重学习 (不假设等权)
  2. 加入缺陷消除率作为 EDSR 的分量
  3. 加入感知响度匹配度
  4. 考虑情绪特异的目标向量 (不共用预设值)
  5. T_EFFECTS 从经验值改为数据驱动的雅可比估计
```
