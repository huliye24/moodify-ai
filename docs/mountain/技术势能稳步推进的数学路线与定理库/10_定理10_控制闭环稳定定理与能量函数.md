# 定理 10：控制闭环稳定定理与能量函数

**来源**: 技术势能稳步推进的数学路线与定理库 §3 定理10
**层级**: 内部工作定理 — 处理不应是单次操作, 而应是稳定的闭环
**状态**: 远期 — 需要代理指标校准后才能可靠运行

---

## 0. 定理陈述

### 0.1 自然语言

如果每轮处理都能降低一个综合能量函数，并且风险保持有界，那么系统可以稳定逼近更好的显影状态。

### 0.2 形式化

定义能量函数：

```
V(x, g) = α * EmotionDistance(x, g)
        + β * DefectPenalty(x)
        + γ * OverprocessingRisk(x)
        + δ * Uncertainty(x)
```

理想状态：

```
V(x_{t+1}, g) < V(x_t, g)
且:
Risk(x_{t+1}) ≤ RiskLimit(g)
```

## 1. 能量函数的四个分量

### 1.1 EmotionDistance(x, g)

```
EmotionDistance = ||StateTransferEngine.diagnostic_to_process(x) - ideal_vector(g)||_2

归一化: ∈ [0, 1]，因为 5D 向量每维 ∈ [0, 1]，最大距离 = sqrt(5) ≈ 2.236
```

### 1.2 DefectPenalty(x)

```
DefectPenalty = Σ (severity_i * weight_i) / Σ weight_i

severity ∈ {1, 2, 3}
weight = 参数在缺陷分类中的优先级权重

归一化: ∈ [0, 3]
```

### 1.3 OverprocessingRisk(x)

```
OverprocessingRisk = max(LFR(x) / 100, ArtifactRisk(x))

LFR: 听力疲劳风险, ∈ [0, 100]
ArtifactRisk: 伪影风险 (泵浦/相位/失真), ∈ [0, 1]

归一化: ∈ [0, 1]
```

### 1.4 Uncertainty(x)

```
Uncertainty = σ_post(x) from the GP surrogate model (定理8)
或:
Uncertainty = 1 - max_similarity(x, history)
              (相似度越低, 不确定性越高)

归一化: ∈ [0, 1]
```

## 2. 权重的确定

α, β, γ, δ 不应该是手工设定的。来源：

```
从校准实验 (定理2) 中:
  让听众对多个版本打分 (EDSR_true)
  同时计算各版本的 V 分量
  用回归: EDSR_true ~ α*ED + β*DP + γ*OR + δ*U
  拟合得到最优权重

初始默认 (校准前):
  α = 0.50  (情绪距离最重要)
  β = 0.25  (缺陷消除次之)
  γ = 0.15  (风险惩罚)
  δ = 0.10  (不确定性, 用于探索)
```

## 3. 闭环控制流程

### 3.1 单步处理

```
Step t:
  1. 诊断当前音频 x_t
  2. 推荐参数 u_t (LLM/RAG/搜索)
  3. 安全投影 u'_t = Project(u_t, U_safe)
  4. DSP 执行: x_{t+1} = DSP(x_t, u'_t)
  5. 诊断新音频 x_{t+1}
  6. 计算 V(x_{t+1}, g)

  若 V(x_{t+1}, g) < V(x_t, g):
    接受, 进入下一轮或停止
  若 V(x_{t+1}, g) ≥ V(x_t, g):
    拒绝, 尝试备选参数或停止
```

### 3.2 多轮迭代

```
最大迭代轮数: N_max = 3
  (超过 3 轮边际收益极低, 过度处理风险急剧上升)

停止条件 (任意满足):
  1. V(x_{t+1}, g) < V_threshold  (达标, 能量够低)
  2. ΔV < ε 连续 2 轮  (边际收益消失)
  3. V(x_{t+1}, g) ≥ V(x_t, g)  (退化, 回退到 x_t)
  4. t = N_max  (达到最大迭代)
```

### 3.3 Lyapunov 式的稳定性分析

在理想情况下（代理指标完美, DSP 可逆或单调）:

```
V(x, g) 是类 Lyapunov 函数:
  - V(x_target, g) = 0   (目标状态能量为零)
  - V(x, g) > 0 for x ≠ x_target
  - ΔV ≤ 0 along the processing trajectory

这保证了处理不会发散或振荡。
```

实际情况下代理指标不完美，ΔV 可能为正（指标判断和真实听感不一致）。这时：
- 监控 V 的实际变化（基于真实诊断, 不是代理预估）
- 连续 2 次 ΔV > 0 → 停止迭代, 标记为代理失效案例

## 4. 过度处理风险的硬约束

### 4.1 风险限制

```
对每种情绪 g, 定义 RiskLimit(g):

GA (温柔觉醒): RiskLimit = 0.4   (保守, 避免过度)
HL (治愈温暖): RiskLimit = 0.4
SE (神圣空灵): RiskLimit = 0.5
LW (孤独留白): RiskLimit = 0.3   (最保守, 保持留白感)
CN (电影感):   RiskLimit = 0.5
DR (黑暗浪漫): RiskLimit = 0.6
UD (都市危险): RiskLimit = 0.8   (允许更多风险)
WL (废土机械): RiskLimit = 0.9   (允许最高风险)
```

### 4.2 风险超标处理

```
若 Risk(x_t, u'_t) > RiskLimit(g):
  减小 u'_t 的强度 (按比例缩放到满足 RiskLimit)
  若缩放后仍超标 → 回退到 fallback 参数
```
