## 1. 安全多面体的完整定义

### 1.1 参数硬边界

```
U_hard = {u | ∀i: lo_i ≤ u_i ≤ hi_i}
```

15 个参数，每个 lo/hi 从以下来源确定：
- craft_chains.py 的 min/max 值（先验）
- 心理声学安全范围（如 P11 > 0.8 导致原始信号淹没）
- 物理限制（如频率不能为负）

### 1.2 组合安全约束

```
U_combo = {u | ∀c ∈ combo_rules: violation(u, c) = False}
```

组合规则示例:
```
R1: P02 + P15 ≤ 8  (中频+高频增益和限制)
R2: P05 > 5 → P11 ≤ 0.3  (低频重时限制混响)
R3: P06 > 6 → P13 ≤ 0.15  (重压缩时限制失真)
R4: min(P02, P15) ≥ -3  (不同时大幅衰减中高频)
R5: P09 < -30 AND P06 > 3 → 高风险 (阈值过低+高压缩比)
```

### 1.3 情绪安全区间

```
U_emotion(g) = {u | safety_lo[g][dim] ≤ translate_to_wavestate(u) ≤ safety_hi[g][dim]}
```

来自 `emotion_targets.py` 的 `get_safety_bounds(emotion)`。

### 1.4 风险门控

```
U_risk = {u | LFR(u) ≤ RiskLimit(g) AND ArtifactRisk(u) ≤ 0.3}
```

### 1.5 完整安全集

```
U_safe = U_hard ∩ U_combo ∩ U_emotion(g) ∩ U_risk
```

## 2. 投影算法

### 2.1 硬边界投影（解析解）

```
proj_hard(u):
  for each param p:
    u'[p] = clip(u[p], lo[p], hi[p])
  return u'
```

### 2.2 组合约束投影（迭代修正）

```
proj_combo(u):
  for each rule in combo_rules:
    while violation(u, rule):
      # 找到最敏感参数, 向满足规则的方向微调
      p_sensitive = argmax_p |∂(violation)/∂(u[p])|
      u[p_sensitive] -= sign(∂/∂p) * step
  return u
```

### 2.3 风险门控投影（比例缩放）

```
proj_risk(u):
  if LFR(u) > RiskLimit(g):
    # 降低所有强度, 按比例
    scale = RiskLimit(g) / LFR(u)
    for each dim in strength_vector:
      u[dim] *= scale
  return u
```

### 2.4 完整投影（顺序执行）

```
proj(u, g):
  u1 = proj_hard(u)
  u2 = proj_combo(u1)
  u3 = proj_emotion(u2, g)
  u4 = proj_risk(u3, g)

  record_projection(u, u4)  # 记录原始 vs 投影后
  return u4
```

## 3. 风险收益不等式

### 3.1 公式

```
ΔEmotionScore ≤ λ(g) * ΔOverprocessingRisk

若不等式不成立 → 不执行该处理 (或降级为 research-mode)
```

### 3.2 λ(g) 的估计

λ 依赖于情绪目标。保守情绪（如 LW）的 λ 高 —— 更不愿意接受风险换收益。激进情绪（如 WL）的 λ 低 —— 接受更多风险。

初始估计（从情绪安全区间反推）:

```
λ(GA) = 2.0  # 温柔, 保守
λ(HL) = 2.0
λ(SE) = 1.5
λ(CN) = 1.5
λ(DR) = 1.2
λ(UD) = 0.8
λ(WL) = 0.5  # 废土, 激进
λ(LW) = 2.5  # 最保守
```

校准: 通过人耳实验，收集听众对不同处理强度的偏好，拟合 λ。

## 4. Fallback 条件

### 4.1 触发条件

```
fallback if any of:
  1. ||u_raw - u_proj|| > 阈值  (投影变形太大, 意味着推荐值严重偏离安全区)
  2. proj 后的 u 导致 EDSR_proxy < preset_EDSR_proxy - margin
  3. RiskLevel = "red"
  4. 连续 3 次投影记录显示同一参数被反复限制
```

### 4.2 Fallback 策略

```
Level 1 fallback: 使用搜索最优 (search_optimal_strengths)
Level 2 fallback: 使用 emotion + preset (get_recommended_params)
Level 3 fallback: 使用最保守预设 (固定所有强度=0.5)
```
