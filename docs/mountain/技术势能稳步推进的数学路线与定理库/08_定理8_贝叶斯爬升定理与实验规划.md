## 0. 定理陈述

### 0.1 自然语言

当真实评估昂贵时，下一次实验应该优先选择「最大预期收益」或「最大信息增益」的候选，而不是随机尝试或均匀覆盖。

### 0.2 形式化

```
f(u) = unknown true utility (需要真实 DSP + 人耳反馈)
surrogate model: estimates f(u)  (从历史数据学习)
acquisition(u) = ExpectedImprovement(u) 或 InformationGain(u)
u_next = argmax_u acquisition(u)
```

## 1. 为什么 LHS 不够

### 1.1 LHS 的优势和局限

LHS (Latin Hypercube Sampling) 确保在 5D 空间中均匀覆盖。这在初始阶段足够好——当我们对 f(u) 一无所知时，均匀覆盖是最优策略。

但：
- LHS 不利用已有的评估数据
- LHS 知道哪些区域已经被探索过但不调整采样
- LHS 不区分「已经确认好的区域」和「高度不确定的区域」

### 1.2 需要主动学习的时机

```
触发条件 (同时满足):
  1. 历史案例 ≥ 200 条 (含处理前后指标)
  2. 其中 ≥ 50 条有人耳反馈
  3. proxy 与 EDSR_true 的 ρ ≥ 0.5 (代理勉强可信)

满足后:
  实验预算 = 每次 DSP 处理 + 人耳评价
  目标 = 用最小实验预算最大化 f(u) 的知识增量
```

## 2. 高斯过程代理模型

### 2.1 模型设定

```
f(u) ~ GP(μ(u), k(u, u'))

先验均值: μ(u) = EDSR_proxy(u)  (代理指标作为先验)
核函数: k(u, u') = σ² * exp(-||u - u'||² / (2 * l²))
          (RBF 核, σ² = 输出方差, l = 长度尺度)
```

### 2.2 后验更新

给定观测数据 D = {(u_i, y_i)}:

```
μ_post(u) = μ(u) + k(u, U) * K^{-1} * (y - μ(U))
σ²_post(u) = k(u, u) - k(u, U) * K^{-1} * k(U, u)
```

其中 K = k(U, U) + σ²_noise * I。

### 2.3 采集函数

**Expected Improvement (EI)**:
```
EI(u) = E[max(0, f(u) - f_best)]
      = (μ_post(u) - f_best) * Φ(Z) + σ_post(u) * φ(Z)
其中 Z = (μ_post(u) - f_best) / σ_post(u)
Φ = CDF of standard normal, φ = PDF
```

**Upper Confidence Bound (UCB)**:
```
UCB(u) = μ_post(u) + κ * σ_post(u)
κ = 2-3 (exploration-exploitation trade-off)
```

**Probability of Improvement (PI)**:
```
PI(u) = Φ((μ_post(u) - f_best - ξ) / σ_post(u))
ξ = small positive number (minimum meaningful improvement)
```

## 3. 主动实验规划流程

```
Input: 历史案例 D, 实验预算 B (如 "做 10 次真实 DSP + 人耳评价")
Output: 排序的实验候选项

Step 1: 用 D 训练 GP 代理模型
Step 2: 对 5D 空间中未评估的区域, 计算采集函数
Step 3: 选择 argmax 采集函数的 u
Step 4: 执行真实 DSP + (可选) 人耳评价
Step 5: 将 (u, y) 加入 D
Step 6: 如果预算未用完, 回到 Step 1

额外约束:
  - 安全多面体投影 (定理5)
  - 不重复评估已知差区域 (采集函数自然处理)
  - 情绪目标分层 (每种情绪独立建模)
```
