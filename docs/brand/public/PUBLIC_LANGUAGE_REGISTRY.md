# Moodify Public Language Registry

> 目的：防止不同网站、App、路演材料和社交媒体再次产生不同版本的 Moodify。

---

## A. 核心公开语言 - 默认允许

| 中文 / 英文 | 用途 | 规则 |
|---|---|---|
| Moodify | 主品牌 | 首选，不附加复杂类别 |
| 每一种声音，都值得被世界听见。 | 品牌信念 | 中文主表达 |
| Every voice deserves to be heard. | 品牌信念 | 英文主表达 |
| Listen. Then Play. | 产品原则 | 可作为 Hero / Section 标题 |
| Play. | 产品动作 | 最强 CTA 之一 |
| Original / Moodify | 声音对比 | 优先于 Before / After 的“修复感” |
| Listen | 动作 | 用于试听 |

---

## B. 次级公开语言 - 有条件允许

| 词语 | 使用位置 | 禁止方式 |
|---|---|---|
| Can machines learn to hear? | Research / About | 不作为产品首屏唯一主标题 |
| Evidence | 技术证明页 | 不让用户先读 Evidence 再理解产品 |
| Research | 公司 / 深层导航 | 不把主站做成实验室首页 |
| Verification | Evidence | 不替代听觉体验 |
| Listening experience | 产品解释 | 避免写成长篇行业术语 |
| Source preserved | 技术说明 | 不占首屏 |

---

## C. 技术层语言 - 默认隐藏

- Listen / Represent / Judge / Intervene / Verify / Learn
- Auditory representation
- Measurement science
- Model tier
- Pipeline
- Deterministic review
- BYPASS
- Source hash
- Evidence chain
- State machine
- Data factory
- FFmpeg / Demucs / Audiolla / Basic Pitch
- PolarDB / OSS / GPU / Worker / Queue

这些词可以真实存在，但不应该成为普通用户理解 Moodify 的前提。

---

## D. 退出当前公共主叙事

以下词汇在 Public Form 阶段不得作为 Hero、首页第一段或主 CTA：

- Auditory Intelligence Infrastructure
- Give machines the ability to hear.
- The Ear of AI
- Build with Moodify
- Developers
- API
- ACU
- Creator Platform
- AI 音乐后处理平台
- AI 音频基础设施
- 老歌修复平台

### 说明

“退出主叙事”不等于从代码和历史中全部删除。

它意味着：

> 用户在还不知道 Moodify 是什么之前，不应该先看到这些词。

---

## E. 文案语气检查

任何对外文案发布前，删掉或重写以下倾向：

- “赋能”
- “生态闭环”
- “颠覆”
- “革命性”
- “行业领先”
- “全栈”
- “下一代基础设施”
- “重新定义行业”
- “全球领先”
- 无法被证明的绝对性 AI 表述

优先使用：

- 短句
- 具体动作
- 可试听证明
- 有限范围的事实
- 不解释也能成立的产品体验
