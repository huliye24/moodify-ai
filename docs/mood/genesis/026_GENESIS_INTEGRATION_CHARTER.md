1. Start from a clean `origin/main` worktree.
2. Absorb reviewed commits, not whole stale worktrees or archive directories.
3. Preserve a single authoritative state and evidence model.
4. Classify every public metric as real, derived, fixture, mock, static, or unverified.
5. Start network counts at the truth, including zero or one.
6. Do not activate or launch a token merely because code compiles.
7. Require explicit human authority for keys, funds, contracts, domains, production deployment, or disclosure of participant data.
