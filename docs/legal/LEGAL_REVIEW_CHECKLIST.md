# Moodify Open-Source Release Checklist

- [ ] Copyright owner and years confirmed
- [ ] GPL choice confirmed: only vs. or-later
- [ ] Official GPLv3 text included without modification
- [ ] SPDX headers applied to covered source files
- [ ] Code/asset/model/data license map completed
- [ ] Dependency license scan completed
- [ ] Corresponding-source build materials identified
- [ ] Generated code and vendored binaries reviewed
- [ ] Customer data, credentials and private evidence removed
- [ ] Trademark notice included
- [ ] Contribution model selected: DCO, CLA, or closed contributions
- [ ] Dual-licensing rights confirmed
- [ ] Server components reviewed for GPL vs. AGPL implications
- [ ] Jurisdiction-specific legal review completed
