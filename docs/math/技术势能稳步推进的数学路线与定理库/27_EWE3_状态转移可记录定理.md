# EWE 定理 3：状态转移可记录定理

**来源**: 母文件 §7 EWE 定理 3
**工程含义**: 每个处理步骤都要记录输入状态、控制量、输出状态

---

## 0. 定理陈述

DSP 的本质不是效果叠加，而是 WaveState 状态转移。

### 0.1 形式化

```
处理链 = T_n ∘ T_{n-1} ∘ ... ∘ T_1

∀i: T_i 定义在 WaveState 空间上:
  WS_i → WS_{i+1}

每个转移步:
  record(WS_i, θ_i, WS_{i+1}, Δ_i)
```

---

## 1. 推理展开

### 1.1 与效果器思维的区别

```
效果器思维: "我加了 EQ, 然后加了压缩, 然后加了混响"
  → 关注的是操作 (做了什么)

状态转移思维: "频谱均衡度从 0.45 变为 0.62, 动态呼吸感从 0.38 变为 0.55"
  → 关注的是结果 (改变了什么)
```

两种思维的差异不是修辞差异。效果器思维下，两个不同的插件链可能产生相同的听感变化——但系统不知道，因为系统只看操作不看结果。状态转移思维下，相同的结果变化被识别为等价的，可以互相替代。

### 1.2 状态转移矩阵

多个处理步骤的累积效果可以用矩阵近似：

```
ΔWS_total ≈ J_n * Δθ_n + ... + J_1 * Δθ_1

其中 J_i = ∂(WS_out) / ∂(θ_i) 是第 i 步的局部雅可比
```

对于线性区（小参数变化），叠加原理成立。对于非线性区（大参数变化或耦合效应），需要二阶修正。

---

## 2. 工程含义

```
1. ProcessingRecord 必须包含完整的 WS_before → WS_after
2. 每条 DSP 链的输出必须经过再诊断
3. 状态转移矩阵从 A3 实验逐步建立 (J = ∂x'/∂s)
4. 未来可以跳过中间步骤直接估计最终状态
```
