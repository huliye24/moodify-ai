# 定理 3：状态空间压缩定理与 5D 灵敏度

**来源**: 技术势能稳步推进的数学路线与定理库 §3 定理3
**层级**: 内部工作定理 — 5D 搜索空间的理论基础
**状态**: P0 优先级 — 5D 是否保留主要可控方向决定搜索有效性

---

## 0. 定理陈述

### 0.1 自然语言

如果 5D 强度空间保留了 15D 参数对 WaveState 的主要影响方向，那么在 5D 空间搜索比直接在 15D 参数空间搜索更容易形成稳定技术势能。

### 0.2 形式化

```
u_15 ∈ R^15          # 15D 参数空间
s_5  ∈ R^5           # 5D 强度空间
M: s_5 → u_15        # 映射函数 (strength_to_params)
T: (x, u_15) → x'    # 状态转移

若:
  T(x, M(s_5)) 能覆盖主要可感知状态转移方向
则:
  Search(s_5) 的样本效率 > Search(u_15)
```

## 1. 为什么压缩是必要的

### 1.1 15D 直接搜索的困境

```
15D 参数空间, 每维取 5 个离散值:
候选数 = 5^15 ≈ 3 × 10^10

即使 LHS 采样 2000 个点:
覆盖率 = 2000 / (3 × 10^10) ≈ 6.7 × 10^(-8)
→ 几乎为零覆盖
```

### 1.2 5D 压缩的合理性

5 个 transfer function 并非随意分组。它们来自声学第一性原理：

| 维度 | 声学含义 | 控制的物理量 |
|------|---------|------------|
| spectrum | 频率能量分布 | EQ gain @ 各频段 |
| dynamic | 响度时间变化 | 压缩比/阈值/启动/释放 |
| space | 空间信息 | 混响参数 |
| layer | 谐波丰富度 | 失真/饱和度 |
| master | 整体平衡 | 全局增益 |

每个维度控制一个独立的声学维度。跨维度的交互存在（如压缩会影响频谱感知），但主效应强于交互效应。

### 1.3 压缩的代价

5D 压缩丢弃的信息：
- 同一维度内参数的精细差异（如 P02 vs P03 的独立调节）
- 频率依赖的动态处理（如只在低频做压缩）
- 情绪特异的空间塑造（如不同混响类型）

## 2. 灵敏度实验设计

### 2.1 单轴扫描

对每个 strength 维度，固定其他 4 维为 0.5，扫描目标维度的 [0.1, 0.9]：

```
for dim in [spectrum, dynamic, space, layer, master]:
    for s in [0.1, 0.2, ..., 0.9]:
        fixed_others = {d: 0.5 for d ≠ dim}
        params = strength_to_params(fixed_others | {dim: s})
        audio_out = DSP(audio_in, params)
        WaveState_out = diagnose(audio_out)
        record(dim, s, WaveState_out)
```

### 2.2 局部雅可比估计

在 s_0 = (0.5, 0.5, 0.5, 0.5, 0.5) 附近做微小扰动：

```
J_ij = ∂(WaveState_i) / ∂(s_j)    # i ∈ {E, D, S, T, H}, j ∈ {1..5}

数值估计:
J_ij ≈ [WS_i(s_0 + Δ_j) - WS_i(s_0 - Δ_j)] / (2 * Δ_j)
其中 Δ_j = 0.05  (在 j 维度上的微小偏移)
```

### 2.3 双轴耦合扫描

对每对 (dim_a, dim_b)，做 3×3 网格：

```
for s_a in [0.3, 0.5, 0.7]:
    for s_b in [0.3, 0.5, 0.7]:
        ...
        记录 WS 输出
```

如果 WS 输出近似等于单轴效应的线性叠加 → 耦合弱。
如果显著偏离 → 存在交互效应，需在搜索中考虑。

## 3. 不可达目标检测

### 3.1 检测方法

```
已知: s_5 的采样范围 [0.1, 0.9]^5
      对应 WaveState 输出的可达区域 R ⊆ [0, 1]^5

对目标情绪的理想 5D 向量 g:
  dist(g, R) = min_{ws ∈ R} ||ws - g||

若 dist(g, R) > 阈值 → g 在当前参数映射下不可达 → 需要额外维度或新映射
```

### 3.2 对每个情绪的不可达分析

```
for emotion in [GA, SE, UD, LW, HL, DR, WL, CN]:
    g = get_ideal_process_vector(emotion)
    采样 s_5 在 [0.1, 0.9]^5 → 得到 WS 点云
    计算 dist(g, 点云)
    记录 min dist 和对应的 s_5
```

如果某情绪的 min dist > 0.15，说明当前 5D 映射无法充分逼近该情绪的理想向量。

## 4. 风格分层分析

不同音乐风格（如钢琴曲 vs 电子乐 vs 人声民谣）的原始 WaveState 分布不同。相同 5D strength 在不同风格上的转移效果可能不同。

```
for style in [piano, electronic, vocal_folk]:
    取 3 首该风格的典型音频
    做单轴扫描
    对比 ΔWaveState 的均值和方差

若方差跨风格显著 → 搜索空间需要风格先验
若均值跨风格稳定 → 5D 搜索有跨风格泛化能力
```
