# EWE 定理 5：风险收益不等式

**来源**: 母文件 §7 EWE 定理 5
**工程含义**: 不是所有「更强处理」都是更高性能

---

## 0. 定理陈述

当情绪显影收益小于过度处理风险增量时，不应默认执行该处理。

### 0.1 形式化

```
ΔEmotionScore ≤ λ(g) * ΔOverprocessingRisk

若不等式不成立:
  → reject the processing (回退到上一个安全版本)
  → or research-mode only (标记为实验性处理, 用户明确知情)
```

λ(g) 依赖于目标情绪 g。保守情绪 (如 LW 孤独留白) 的 λ 高，激进情绪 (如 WL 废土机械) 的 λ 低。

---

## 1. λ(g) 的估计

### 1.1 初始估计

从情绪的「可接受风险」反推：

```
λ = 1 / AcceptableRisk(g)

AcceptableRisk(g) 来自 RiskLimit(g):
  LW: RiskLimit=0.3 → λ=3.3
  GA: RiskLimit=0.4 → λ=2.5
  HL: RiskLimit=0.4 → λ=2.5
  SE: RiskLimit=0.5 → λ=2.0
  CN: RiskLimit=0.5 → λ=2.0
  DR: RiskLimit=0.6 → λ=1.7
  UD: RiskLimit=0.8 → λ=1.25
  WL: RiskLimit=0.9 → λ=1.1
```

### 1.2 校准方案

通过 A2 校准实验的 A/B 数据拟合 λ:

```
对每对比较 (version_A, version_B):
  若 A 被选择:
    ΔE = EDSR_proxy(A) - EDSR_proxy(B)
    ΔR = Risk(A) - Risk(B)
    → 有效样本: A 被选择 且 ΔE > 0 且 ΔR > 0
    → λ 的 MLE 估计: 使 P(choose A | ΔE, ΔR) 最大化的 λ
```

---

## 2. 工程含义

```
1. 每次 DSP 处理前, 计算 ΔEmotionScore (预估) 和 ΔRisk (预估)
2. 如果不等式不成立, 不执行 → 回退到上一个安全版本
3. 记录所有被拒绝的处理方案, 作为"风险边界"的数据点
4. 如果某个情绪目标连续被拒绝 ≥ 5 次,
   说明 RiskLimit 或 λ 需要重新校准
```
