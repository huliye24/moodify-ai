# EWE 定理 4：人耳终裁定理

**来源**: 母文件 §7 EWE 定理 4
**工程含义**: 没有 A/B 或主观评价, EDSR 不能闭合

---

## 0. 定理陈述

指标可以指导搜索，但人耳偏好定义最终 EDSR_true。

### 0.1 形式化

```
EDSR_proxy = f(WS_raw, θ, WS_processed)  # 可计算, 但可能失真
EDSR_true   = HumanPreference(音频_A, 音频_B)  # 昂贵, 但是金标准

EDSR_proxy 只有在 Corr(rank(proxy), rank(true)) ≥ τ 时才能替代
EDSR_true 用于闭环校准和 Goodhart 防护
```

---

## 1. 推理展开

### 1.1 为什么指标不能替代人耳

```
1. 指标测量的是维度, 人耳感知的是整体
   维度评分 = 对 5 个维度的加权和
   整体感知 = Gestalt (格式塔) — 大于部分之和

2. 指标是线性的, 人耳是非线性的
   2dB EQ 增益的 WHS 变化 ≈ 2× 1dB EQ 增益的 WHS 变化
   但人耳对 2dB 的感知 ≠ 2× 对 1dB 的感知 (Weber-Fechner 定律)

3. 指标不知道"风格"
   WHS 偏好更宽的立体声 (相关性更高)
   但某些风格 (如 Lo-fi) 刻意的窄立体声是审美选择
```

### 1.2 最低成本的人耳反馈协议

详见 P0-1 文章 §1.3。关键设计原则：

```
1. 不追求统计显著 (大样本), 而追求信号质量 (好样本)
2. 每人评 50-100 对, 控制在 30 分钟内
3. 插入隐藏重复和质量锚定对
4. 对低信度听众降权而非排除
```

## 2. 工程含义

```
1. EDSR_true 必须通过校准实验 (A2) 建立
2. 代理指标与 EDSR_true 的 ρ 必须定期监控 (A6)
3. 高价值决策必须有人耳验证 (如新情绪上线)
4. 自动处理管线可以无人耳运行, 但标记为 "unverified"
```
