## 0. 问题陈述

每个 strength 维度到底改变了 WaveState 的哪一部分？是否有耦合？是否有不可达目标？5D 强度→15D 参数→DSP→WaveState 这条链的可控性如何？

---

## 1. 可控性定义

### 1.1 状态转移的雅可比

```
J ∈ R^(5×5):
  J_ij = ∂(WS_out_i) / ∂(s_j)

若 rank(J) = 5 → 5D 强度对 5D WaveState 是完全可控的
若 rank(J) < 5 → 存在不可控子空间
```

### 1.2 条件数

```
κ(J) = σ_max(J) / σ_min(J)

κ < 10: 各方向灵敏度均衡
10 ≤ κ < 50: 某些方向明显更难控制
κ ≥ 50: 存在近似不可控方向
```

## 2. 实验设计

### 2.1 单轴扫描 (定理3 扩展)

```
对每个维度 dim ∈ {spectrum, dynamic, space, layer, master}:
  固定其他 4 维为 0.5
  扫描 dim ∈ [0.1, 0.9], step=0.1

  对每个强度值 s:
    1. params = strength_to_params(strength_vector)
    2. audio_out = spectral_chain.process(audio_in, params)
    3. ws_out = diagnose(audio_out)
    4. 记录: (dim, s, ws_out.E, ws_out.D, ws_out.S, ws_out.T, ws_out.H)

输出: 5 张图, 每张 x轴=strength, y轴=5D WaveState 的各维变化
```

### 2.2 双轴耦合 (定理3 扩展)

```
对每对 (dim_a, dim_b), a < b:
  网格: s_a ∈ [0.3, 0.5, 0.7], s_b ∈ [0.3, 0.5, 0.7]

  对每个 (s_a, s_b):
    run DSP + diagnose
    记录 ws_out

  计算耦合度:
    for each ws_dim:
      predicted = ws_out(s_a=0.5, s_b=0.5) + Δ(s_a) + Δ(s_b)  (线性叠加假设)
      actual = ws_out(s_a, s_b)
      interaction = actual - predicted
      若 ||interaction|| > 阈值 → 存在耦合
```

### 2.3 不可达目标 (定理3 扩展)

```
for each emotion ∈ [GA, SE, UD, LW, HL, DR, WL, CN]:
  g = get_ideal_process_vector(emotion)

  # LHS 采样 2000 个点在 [0.1, 0.9]^5
  sampled_ws = [apply_chain_transfer(diagnostic_to_process(x), sv) for sv in sampled_strengths]

  min_dist = min(||ws - g|| for ws in sampled_ws)

  if min_dist > 0.15:
    mark emotion as "partially unreachable in 5D"
    record the closest achievable ws and corresponding strength
```

## 3. 鲁棒性分析

### 3.1 跨歌曲的方差

```
取 3 首不同风格的测试曲
对每首歌做单轴扫描

计算:
  mean_ΔWS(dim, s, ws_dim) = 3 首歌的平均
  std_ΔWS(dim, s, ws_dim) = 3 首歌的标准差

若 std/mean > 0.5 → 灵敏度在不同歌曲上有显著差异
  → 可能需要风格先验来调整搜索空间
```

### 3.2 诊断噪声的影响

诊断引擎的 18 参数有测量噪声（±2-5%）。噪声会影响雅可比估计。

```
对同一首歌, 重复诊断 5 次
计算每个参数的重复性: σ / μ

若某参数的 σ/μ > 0.1 → 该参数的测量不够稳定
  → 在搜索中降低对该参数的依赖
```

## 4. 判断标准

```
若满足以下全部条件 → 5D 搜索有效:
  [ ] rank(J) = 5
  [ ] κ(J) < 50
  [ ] 所有情绪的 min_dist < 0.15
  [ ] 跨歌曲 std/mean < 0.5
  [ ] 主要诊断参数的 σ/μ < 0.1

若有条件不满足 → 需要:
  - 增加搜索维度 (如分离 spectrum 为 spectrum_low + spectrum_high)
  - 引入风格先验
  - 重新校准 T_EFFECTS
```
