# 定理 4：记忆复利定理与负迁移防护

**来源**: 技术势能稳步推进的数学路线与定理库 §3 定理4
**层级**: 内部工作定理 — RAG 有效性的前提
**状态**: P0 优先级 — 不防护负迁移, RAG 可能越用越差

---

## 0. 定理陈述

### 0.1 自然语言

历史案例只有在「记录完整、检索相关、反馈可信」三者同时成立时，才会形成正向复利。三者任意缺失，历史可能变成噪声甚至毒药。

### 0.2 形式化

```
Case = (x_raw, g, u, x_final, y_feedback, risk, context)
Retrieve(x, g) → K similar cases
Recommend(K, x, g) → u'

若:
  similarity 与真实迁移收益正相关
且:
  feedback 噪声可控
则:
  Memory_{t+1} 提升 RecommendationQuality
```

反例：如果相似检索只按频谱近似但忽略目标情绪，系统可能把「清澈温柔」的历史参数迁移到「废土机械」，形成负迁移。

## 1. 负迁移的类型与检测

### 1.1 类型 1：频谱相似但情绪冲突

```
历史案例: 钢琴曲, AirBand=-16dB, 目标=温柔觉醒 (GA)
         处理: P15=+1.5dB (温和提亮)
当前输入: 钢琴曲, AirBand=-16dB, 目标=废土机械 (WL)
         检索到上述案例 (频谱高度相似)
         RAG 推荐 P15=+1.5dB → 但 WL 要求高频更激进或更多失真
         → 负迁移
```

检测方法：目标情绪不匹配时降低检索权重或排除。

### 1.2 类型 2：表面相似但结构不同

```
历史案例: 人声民谣, VocalSNR=12dB, 满意
当前输入: 电子乐有人声采样, VocalSNR=12dB
         检索到上述案例 → 推荐民谣的参数
         → 电子乐被处理成民谣质感 → 负迁移
```

检测方法：在检索向量中加入风格/类型特征。

### 1.3 类型 3：用户偏好噪声

```
历史案例: 用户说"满意"但只是随便点的
          → 低质量正样本进入检索
         → 后续推荐被带偏
```

检测方法：用户反馈需要信度权重（如反馈速度、是否有二次调整）。

## 2. 相似度定义的四个分量

当前 `find_similar` 只用 14 维诊断向量的余弦相似度。这不够。

### 2.1 四分量相似度

```
Sim(C_new, C_hist) =
    w1 * Sim_diagnosis(d_new, d_hist)    # 诊断相似
  + w2 * Sim_target(g_new, g_hist)       # 目标相似
  + w3 * Sim_risk(r_new, r_hist)         # 风险相似
  + w4 * Sim_outcome(o_new, o_hist)      # 结果相似 (如果有)
```

#### 诊断相似 (w1)

余弦相似度。14 维归一化诊断向量。当前已实现。

#### 目标相似 (w2)

```
Sim_target(g_new, g_hist) =
  1.0  if g_new == g_hist
  0.7  if g_new 和 g_hist 同类别 (如都是"温暖"类)
  0.3  if 不同类别但情绪方向不冲突
  0.0  if 方向相反 (如温柔 vs 废土)
```

#### 风险相似 (w3)

```
Sim_risk(r_new, r_hist) =
  cos(r_new.defect_vector, r_hist.defect_vector)
```
缺陷向量：对每个 18 参数，记录其 severity ∈ {0, 1, 2, 3}。

#### 结果相似 (w4)

仅当历史案例有 `edsr_real` 时才可用。
```
Sim_outcome = 1 - |EDSR_real_new_est - EDSR_real_hist| / 100
```
新案例的 EDSR_real 未知时，此项权重 w4=0。

### 2.2 权重学习

初始权重: w = (0.35, 0.25, 0.25, 0.15)

权重更新：当积累 ≥50 条带真实反馈的案例后，用 leave-one-out 交叉验证优化权重。

```
目标函数: maximize Kendall τ between predicted similarity rank and actual transfer benefit
```

## 3. 负迁移防护层

### 3.1 情绪过滤

```
Retrieved_cases = cases WHERE emotion_code == target_emotion_code
                  OR (emotion_category == target_category AND similarity > 0.8)
```

### 3.2 失败案例反向检索

失败案例（satisfied=False）不进入正向推荐，但进入反向参考：
- 如果当前诊断与失败案例高度相似 → LLM prompt 中标注「避免以下参数模式」
- 历史失败的参数范围被标记为「高风险区域」

### 3.3 置信度门控

```
if max_similarity < 0.5:
    skip RAG entirely, fall back to search
elif max_similarity < 0.7:
    use RAG but with lower weight in final recommendation
elif max_similarity >= 0.7:
    RAG is primary, search is verification
```

## 4. 历史案例的生命周期

### 4.1 时间衰减

```
effective_weight = similarity * exp(-age_days / 180)
```

半衰期 180 天。1 年前的案例权重 ≈ 13%。

### 4.2 反馈驱动的置信度衰减

```
case_confidence =
  1.0                        if satisfied=True (明确满意)
  0.7                        if satisfied=None (无反馈)
  0.3                        if satisfied=False (明确不满意, 用于反向参考)
  fixed_to_0                 if flagged as bad case
```

### 4.3 遗忘条件

```
forget case if:
  age_days > 365                                    # 过旧
  OR (satisfied=False AND age_days > 90)            # 失败案例加速遗忘
  OR flagged_as_harmful                              # 标记为有害
```
