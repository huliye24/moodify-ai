## 0. 定理陈述

### 0.1 自然语言

只有当历史数据覆盖足够、反馈标签可信、教师输出经过验证时，才应该启动蒸馏模型。过早蒸馏只是 LLM 的有损压缩。

### 0.2 形式化

```
Train student model S on: (x_raw, g, retrieved_cases) → u

若:
  Coverage ≥ threshold_coverage
  LabelQuality ≥ threshold_label
  TeacherValidity ≥ threshold_teacher
则:
  Distillation 可进入主路线
否则:
  继续 API + RAG + 搜索
```

## 1. 三个门槛的精确定义

### 1.1 Coverage Index（覆盖率）

```
Coverage = 四种覆盖率的几何平均:

Coverage_emotion = |{目标情绪已覆盖}| / 8
  阈值: ≥ 0.75 (6/8)

Coverage_defect = |{缺陷类型(DEF-001 ~ DEF-017) 已出现 ≥ 5 次}| / 17
  阈值: ≥ 0.5 (9/17)

Coverage_style = |{风格标签(钢琴/电子/民谣/摇滚/...) 已出现 ≥ 5 次}| / |风格总数|
  阈值: ≥ 0.5

Coverage_generator = |{AI 生成器(Suno v3/v4, Udio, ...) 已出现 ≥ 5 次}| / |生成器总数|
  阈值: ≥ 0.5

Coverage = (C_emotion * C_defect * C_style * C_generator)^(1/4)
阈值: ≥ 0.5
```

含义：四种覆盖率的几何平均 ≥ 0.5 才认为数据有足够多样性。

### 1.2 Label Quality Index（标签质量）

```
LabelQuality = precision * recall * consistency

precision = |标注为"满意"且 EDSR_true > 0.5| / |标注为"满意"的总数|
recall = |EDSR_true > 0.5 中被标注为"满意"| / |EDSR_true > 0.5 的总数|
consistency = 同一听众对同一样本的重复标注一致率

阈值: ≥ 0.7
```

### 1.3 Teacher Agreement Index（教师一致性）

```
对同一 (x_raw, g):
  分别调用: DeepSeek API (teacher 1)
            GPT-4o (teacher 2, 可选)
            搜索 + proxy (teacher 3)

TeacherAgreement = 1 - (std of 3 teachers' recommended u) / (mean range of u)
阈值: ≥ 0.7
```

含义：不同来源推荐的参数越一致，教师输出越可信。

## 2. 蒸馏什么：参数 vs 强度

### 2.1 蒸馏 5D strength 的理由

直接蒸馏 15D 参数有三个问题：
1. 参数之间有复杂约束和相关性，学生模型难以学到
2. 15D 输出空间太大，需要更多训练数据
3. 参数的物理含义不直接，学生模型的错误更危险

蒸馏 5D strength 的优势：
1. 空间维度低 3 倍
2. strength 到参数有确定性映射（`strength_to_params`）
3. 安全投影层仍然有效（在参数层做投影）

### 2.2 学生模型的输入输出

```
输入:
  - diagnosis_vector: 14 维归一化诊断向量
  - emotion_code: one-hot 8 维
  - (可选) retrieved_cases_summary: 固定长度向量 (如 top-3 案例的平均 strength)

输出:
  - strength_vector: 5 维, 每维 ∈ [0, 1]
```

### 2.3 模型架构

初始选择: 小型 MLP (3-4 层, 每层 64-128 单元)
输入 22-30 维 → 64 → 128 → 64 → 5 维输出 (sigmoid)

理由:
- 足够小以便本地部署 (CPU 推理 < 10ms)
- 参数数量 < 20K, 可以用少量数据训练
- 输出层 sigmoid 天然限制在 [0, 1]

## 3. 蒸馏数据的构造

### 3.1 正样本

从历史案例中选择 satisfied=True 的案例：

```
S_positive = {(x_i, g_i, u_i) | satisfied_i = True, EDSR_true_i > 0}
```

### 3.2 合成数据增强

对于覆盖不足的诊断区域，用以下方式生成合成样本：

```
对已有样本做小扰动:
  x' = x + ε, ε ~ N(0, 0.02 * diag(var(x)))
  u' = u + δ, δ ~ N(0, 0.03)  (小扰动, 假设局部平滑)

筛选: u' 必须在安全多面体内
```

### 3.3 教师标注

对无反馈的历史案例，用 DeepSeek API 补标注：

```
Prompt: "以下是处理前后的诊断数据和使用的参数。用户会满意这个处理结果吗？请用 0-100 打分。"
```

这个标注不如真实人耳反馈可靠，但可以填补初期数据的缺口。

## 4. 离线评估

蒸馏模型训练完后，不直接上线。先在离线测试集评估：

```
测试集: 50 个未参与训练的案例

评估指标:
  1. MSE(student_u, teacher_u)  # 输出偏差
  2. Kendall τ between student_ranking and teacher_ranking on 测试集
  3. 安全违规率 (student 输出被投影修改的比例)
  4. Fallback 率 (student 输出置信度 < 阈值时回退到搜索)

上线条件:
  τ ≥ 0.7 AND 安全违规率 < 5% AND MSE < 0.02
```
