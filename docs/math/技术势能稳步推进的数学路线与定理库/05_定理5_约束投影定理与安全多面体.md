# 定理 5：约束投影定理与安全多面体

**来源**: 技术势能稳步推进的数学路线与定理库 §3 定理5
**层级**: 内部工作定理 — DSP 执行的硬安全约束
**状态**: P0 优先级 — 无约束投影, LLM/RAG/搜索的输出都不安全

---

## 0. 定理陈述

### 0.1 自然语言

任何来自 LLM、RAG、搜索或模型的参数建议，都必须投影到安全可执行集合中，才允许进入 DSP。LLM 可以建议，RAG 可以迁移，搜索可以探索——但 DSP 只能执行通过约束层的参数。

### 0.2 形式化

```
u_raw = Recommendation(LLM | RAG | Search | Model)
U_safe = {u | hard_limits(u) ∧ risk(u) ≤ limit ∧ fallback_available}
u_exec = Projection(u_raw, U_safe)

若 u_raw ∉ U_safe:
  执行 u_exec 或 fallback, 不执行 u_raw
```

## 1. 安全多面体的构成

### 1.1 硬边界（hard_limits）

每个 DSP 参数的物理/声学安全范围：

| 参数 | 安全下界 | 安全上界 | 单位 | 超界后果 |
|------|---------|---------|------|---------|
| P01 vocal_presence_freq | 1500 | 6000 | Hz | 超出人声核心频段, 无效处理 |
| P02 vocal_presence_gain | -6 | +10 | dB | >+10dB 可能导致刺耳或啸叫感 |
| P05 proximity_low_gain | -8 | +8 | dB | >+8dB 可能导致浑浊 |
| P06 compression_ratio | 1.0 | 20.0 | :1 | >20:1 几乎等于限幅, 动态全失 |
| P11 reverb_dry_wet | 0.0 | 0.8 | - | >0.8 原始信号被淹没 |
| P13 harmonic_drive | 0.0 | 0.8 | - | >0.8 严重失真 |
| P15 high_shelf_gain | -6 | +10 | dB | >+10dB 高频刺耳 |

### 1.2 组合禁区

某些参数组合虽然单项在安全范围内，组合后危险：

| 组合 | 危险 | 规则 |
|------|------|------|
| P02 > 4 AND P15 > 4 | 中高频叠加过亮 | max(P02, P15) ≤ 6 或两者之和 ≤ 8 |
| P05 > 5 AND P11 > 0.4 | 低频浑浊 + 混响 → 声音糊掉 | 若 P05 > 5, P11 ≤ 0.3 |
| P06 > 6 AND P13 > 0.3 | 重度压缩 + 失真 → 听觉疲劳 | 若 P06 > 6, P13 ≤ 0.15 |
| P02 < -3 AND P15 < -3 | 中频和高频同时大衰减 → 闷 | P02 和 P15 不同时 < -3 |

### 1.3 情绪特例

某些情绪有特殊的边界放宽：

| 情绪 | 放宽 | 理由 |
|------|------|------|
| WL (废土机械) | P13 上限放宽到 1.0 | 失真是其核心特征 |
| UD (都市危险) | P06 上限放宽到 30 | 极限压缩是其特征 |
| SE (神圣空灵) | P11 上限放宽到 1.0 | 超大混响是其特征 |

## 2. 投影策略

### 2.1 最近安全点投影

```
u_exec = argmin_{u ∈ U_safe} ||u - u_raw||_2
```

对于凸安全集，这是凸投影，有解析解。对于非凸集合（组合禁区导致），需要用数值方法。

### 2.2 分级投影

```
Level 1: 硬边界裁剪
  for each param p:
    u[p] = clip(u[p], hard_min[p], hard_max[p])

Level 2: 组合禁区检查
  对每条组合规则:
    if violation:
      调整最敏感参数直到满足规则

Level 3: 情绪特例释放
  对当前情绪的放宽维度:
    若 u[p] 在放宽范围内且被 Level 1/2 限制, 释放到放宽边界

Level 4: fallback 检查
  if u 仍在 U_safe 外 (计算精度或未建模禁区):
    u = fallback_params
```

### 2.3 投影前后的记录

每次投影必须记录：

```json
{
  "u_raw": {"P02": 5.5, "P15": 5.0},
  "u_exec": {"P02": 4.5, "P15": 3.5},
  "projection_reason": "P02+P15 combo rule triggered",
  "violated_rules": ["combo_mid_high_overlap"]
}
```

## 3. 风格化失真 vs 伪影失真的区分

### 3.1 定义

| 类型 | 成因 | 听感 | 是否允许 |
|------|------|------|---------|
| 风格化失真 | WL 的谐波驱动 > 0.5 | 粗糙但有意图 | 允许（在情绪特例内） |
| 伪影失真 | 过度压缩 + 过度EQ | 抽吸/相位/刺耳 | 不允许 |

### 3.2 检测边界

```
style_distortion: P13 > 0.5 AND emotion_code in [WL, UD]
                 → 允许, 但标记为 "风格化处理"

artifact_risk: P06 > 8 AND emotion_code not in [WL, UD]
              → 高风险, 强制降级
```
