# EWE 定理 2：诊断先行定理

**来源**: 母文件 §7 EWE 定理 2
**工程含义**: 任何 DSP 链执行前都必须有诊断对象

---

## 0. 定理陈述

没有 WaveState 诊断，就不存在可验证处理。

### 0.1 形式化

```
∀ 处理操作 T:
  ∃ D(T.input) = WaveState_before
  ∧ ∃ D(T.output) = WaveState_after
  ⇒ 处理效果可验证

若 D 不可用:
  处理效果不可知 → T 只能盲操作 → 不可进入自动推荐管线
```

---

## 1. 推理展开

### 1.1 诊断是反馈回路的传感器

在控制论框架中，诊断引擎是传感器。没有传感器，就没有反馈。没有反馈，就没有闭环。

```
开环 (无诊断): 参数 → DSP → 输出 → ? (不可知)
闭环 (有诊断): 诊断 → 参数 → DSP → 诊断 → 比较 → 调整
```

### 1.2 最小诊断字段

如果为了速度需要轻量诊断，哪些字段是关闭反馈回路的最小必要集？

```
最小集 V1 (5 维, 用于 EDS):
  E (频率均衡度), D (动态呼吸感), S (空间层次感),
  T (瞬态清晰度), H (谐波丰富度)

完整集 V2 (18 参数, 用于 WHS + 缺陷分类):
  Spectrum (5) + Dynamics (4) + Space (4) + Layers (4) + Emotion (4)
```

---

## 2. 工程含义

```
1. WorkflowOrchestrator.process() 必须在 Phase 1 完成诊断后
   才允许进入 Phase 3 DSP

2. 如果诊断失败 (文件损坏/格式不支持):
   处理必须中止, 不能跳过诊断直接 DSP

3. 手动模式 (用户自己调参数):
   诊断仍然执行但不阻塞处理, 标记为 "盲处理" 并记录风险
```
