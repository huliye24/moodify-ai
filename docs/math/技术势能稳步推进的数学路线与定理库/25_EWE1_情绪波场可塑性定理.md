# EWE 定理 1：情绪波场可塑性定理

**来源**: 母文件 §7 EWE 定理 1
**层级**: 文川院情绪波工程学核心定理
**工程含义**: 必须保留 raw → processed 的状态记录

---

## 0. 定理陈述

AI 生成音乐不是固定成品，而是可被诊断、重构、显影的原始情绪波场。

### 0.1 形式化

```
设 A 为 AI 生成的音频信号。
∃ 诊断函数 D: A → WaveState
∃ 处理函数 P: (WaveState, θ) → WaveState'
使得: D(P(A, θ)) ≠ D(A)  (波场状态可改变)
且: 改变方向可被 5D 情绪向量引导
```

### 0.2 逆命题

如果 AI 音乐是固定成品，则任何 DSP 处理只会改变表面特征而不改变情绪表达。Moodify 的全部工作建立在逆命题为假的基础上。

---

## 1. 推理展开

### 1.1 可塑性的三个层次

```
L1: 频谱可塑性 — EQ 改变频率能量分布 (已验证, 确定)
L2: 动态可塑性 — 压缩改变响度时间结构 (已验证, 确定)
L3: 情绪可塑性 — 频谱+动态+空间+层级的联合变化改变情绪感知 (假设, 待验证)
```

L1 和 L2 是 DSP 的基本事实。L3 是 Moodify 的核心假设——5D 状态转移能改变情绪感知。

### 1.2 可塑性的边界

并非所有情绪方向都可达。可塑性边界由以下因素定义：

```
可达区域 = {WS' | ∃ θ ∈ U_safe: WS' = P(WS_raw, θ)}

边界:
  - 物理边界: 音频的频谱上限 (Nyquist) 和动态下限 (噪声地板)
  - 感知边界: 人耳可分辨的最小变化 (JND)
  - 安全边界: U_safe 的投影范围
  - 风格边界: 过度改变会破坏原始风格识别
```

### 1.3 不同 AI 生成器的可塑性差异

```
假设: 不同生成器 (Suno v3/v4, Udio) 产生的原始波场有不同的可塑性范围。

实验设计:
  对同一 prompt 在不同生成器上生成的音乐:
    施加相同的 θ
    测量 ΔWaveState
    比较 Δ 的均值和方差

若方差显著 → 可塑性依赖于生成器 → 搜索空间需要生成器先验
若方差不显著 → 可塑性是生成器无关的 → 搜索空间可统一
```

---

## 2. 工程含义

```
1. 每次处理必须保存 WS_raw 和 WS_processed
2. 状态转移记录格式: (WS_before, θ, WS_after, ΔWS)
3. 可塑性边界通过不可达目标分析 (A3) 逐步映射
```
