# 下一首歌 — 分轨重制生产检查表

复制本表到新 Project / Cue 的制作记录中。勾选表示已有证据，不表示听感自动通过。

## A. Intake

- [ ] 原始成品已只读保存并计算 hash
- [ ] BPM、拍号、调号及其来源已记录
- [ ] 分轨文件齐全，采样率、位深、时长和起点一致
- [ ] 每根分轨的来源、模型/版本、生成时间已记录
- [ ] MIDI/MusicXML 的来源与版本已记录
- [ ] 本曲必须保护的内容已由人填写（音色、情绪、咬字、动态或空间）

## B. HEAR / JUDGE BEFORE

- [ ] 原版完成完整检测
- [ ] 分轨逐轨检测：削波、异常采样、噪声、串音、分离残留
- [ ] 主唱/伴唱问题按时间点记录，不做全段猜测
- [ ] MIDI/曲谱与音频完成对齐或明确标为未校准
- [ ] 处理目标、允许修改与禁止修改已记录

## C. 分轨门禁

- [ ] 无处理分轨重组已生成
- [ ] roundtrip 判据、容差和来源已记录
- [ ] `roundtrip.passed === true`

若上一项未通过：停止自动深度修音；保留失败证据，只能进入显式实验或由人选择仅立体声路径。

## D. A / B 重制

- [ ] A、B 均为完整候选，不是零散预览
- [ ] A 为保守、小幅、可逆方案
- [ ] B 为变化更充分的方案，但不标称更好
- [ ] 音高/节奏仅修改有证据的局部事件
- [ ] 修音与复合分别留下 Mix Graph/参数/版本
- [ ] 没有覆盖 ORIGINAL、旧 A 或旧 B
- [ ] 参数标记为 `CALIBRATED` 或 `UNCALIBRATED_ENGINEERING_DEFAULT`

## E. JUDGE AFTER / 复检

- [ ] ORIGINAL、A、B 使用同一分析链复检
- [ ] 响度、真峰、LRA、削波、相位、单声道和频谱对齐
- [ ] 差异不能只用总分表示；保留逐项事实
- [ ] 手机、耳机、小音箱、单声道试听已记录；未做则为 `NOT_PROVIDED`
- [ ] 任何伪影、齿音、爆音、接缝、混响尾部问题已按时间点记录

## F. 人工选定与交付

- [ ] 人工选择 `A / B / ORIGINAL`
- [ ] reviewer、时间、理由、试听设备已写入只追加决策账本
- [ ] 交付 WAV、试听编码、hash、参数与 rollback 路径齐全
- [ ] 权利、署名和客户规格已确认
- [ ] 最终状态没有把 `TECHNICAL_PASS` 写成“听感一定更好”

## G. MATLAB 实验记录（如使用）

- [ ] MATLAB 版本与工具箱版本
- [ ] 输入文件 hash
- [ ] 脚本 commit / hash
- [ ] 完整参数与随机种子
- [ ] 输出指标、图表与失败日志
- [ ] 实验结论标明 `事实 / 推断 / 人工判断`
- [ ] 若提议迁入 Core，已有第二首及以上歌曲复验与自动测试
