## Read this first

The current Moodify product model is:

```text
ONE BRAND
Moodify

ONE PUBLIC PRODUCT
Moodify Music

TWO PUBLIC PLAYBACK TERMINALS
Web + App

ONE PUBLIC ENTRY
Official Website

ONE INTERNAL AUDITORY SYSTEM
Moodify Ear
```

The shortest product path is:

```text
Official Website
  -> Moodify Music Web or App
  -> Play / Pause / Previous / Next
```

The internal production path is:

```text
Source
  -> Moodify Ear
  -> Judge
  -> Intervention or BYPASS
  -> Verify
  -> Playback-ready Asset
  -> Catalogue
  -> Play
```
