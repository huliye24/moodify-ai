## 实测性能

### 端到端管道（诊断 → 搜索 → DSP → 再诊断）

| 环节 | 耗时 | 占比 |
|------|------|------|
| 诊断引擎 | 203ms | 3% |
| 搜索（2000 LHS 样本） | 156ms | 3% |
| **DSP 处理** | **5786ms** | **94%** |
| **单情绪总计** | **~6s** | 100% |

- DSP 是绝对瓶颈（94%），主要是 pedalboard 音频效果链的渲染
- 搜索极快（16 核 LHS 采样 2000 点仅 156ms）
- 诊断引擎完全确定性（50 次重复 CV=0%）

### 大规模实验（SPEC-017 参照）

| 实验 | 规模 | 预估耗时 |
|------|------|----------|
| B 矩阵 8情绪×2000样本 | 16,000 次 DSP | ~30 min |
| 参数灵敏度扫描（15参数×11步） | 165 次搜索 | ~30 min |
| 25组合（5音频×5情绪） | 25 次全流程 | ~3 min |
| 诊断噪声底（50重复） | 50 次诊断 | ~10s |

## 注意事项

- **按量计费**: 关机不收费，运行收费。不用时务必关机
- **无 GPU**: 所有计算在 CPU 上完成，适合参数化 DSP 但不适合深度学习推理
- **网络限制**: GitHub、Ollama 等国外服务下载速度慢或被墙。PyPI 访问正常
- **安全组**: 需在腾讯云控制台配置入站规则。UFW 已配置但安全组优先
- **每次关机前**: 运行 `bash sync_cloud.sh` 同步数据到本地。关机后云端数据清空
