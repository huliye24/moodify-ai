# Example Preset Card

## Preset ID

PRESET-PLASTIC-WARM_TEXTURE-v0.1

## Target Problem

AI 音乐中频质感偏薄、高频发亮但不通透、整体有塑料感。

## Maturity

EXPERIMENTAL

## Applicable Inputs

- AI generated pop
- cinematic electronic demo
- thin vocal texture

## Not Applicable Inputs

- high-quality commercial master
