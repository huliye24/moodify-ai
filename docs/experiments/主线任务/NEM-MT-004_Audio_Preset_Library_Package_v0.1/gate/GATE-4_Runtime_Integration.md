# Gate 4｜Runtime 接入

## 目标

preset 能被 Runtime 批量调用，并输出标准结果。

## 通过条件

- 相关文件齐全；
- 输出可复现；
- 状态记录完整；
- 没有跳过必要验证；
- 可进入下一 Gate。

## 不通过条件

- preset 无适用范围；
- 没有 MRS 前后记录；
- 只凭一次样本效果就升级成熟度；
- 参数不可复现；
- 命名和版本混乱；
- 存在响度作弊或高质量输入破坏。
