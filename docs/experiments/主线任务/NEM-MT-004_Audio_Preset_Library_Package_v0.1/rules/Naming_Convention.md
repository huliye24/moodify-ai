# Naming Convention

## Preset ID

```text
PRESET-{CATEGORY}-{SHORT_NAME}-v{MAJOR}.{MINOR}
```

示例：

```text
PRESET-PLASTIC-WARM_TEXTURE-v0.1
PRESET-SPATIAL-DEPTH_REPAIR-v0.1
PRESET-DYNAMIC-BREATH_RECOVERY-v0.1
```

## 文件命名

```text
preset_specs/{preset_id}.yaml
reports/{preset_id}_evaluation.md
logs/{preset_id}_run.log
```

## 分类命名

分类目录使用小写英文和下划线：

```text
spectral_balance
transient_repair
dynamic_recovery
vocal_texture
spatial_reality
plastic_reduction
mastering_polish
```
