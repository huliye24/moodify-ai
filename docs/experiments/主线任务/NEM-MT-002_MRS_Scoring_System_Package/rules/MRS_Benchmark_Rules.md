# MRS Benchmark Rules｜MRS 跑分系统规则

## 1. MRS 的定义

MRS 是 Moodify Reality Score，是 Moodify 用来衡量 AI 音乐真实度的开放跑分单位。

## 2. 方向

```text
MRS 越高，代表声音越接近真实。
```

## 3. 无满分原则

MRS 不采用 0-100 满分制。它应像硬件跑分或基准测试一样允许长期突破。

## 4. 基线原则

初期可以将基线样本集合的中位数校准到约 1000 MRS。1000 不是满分，而是早期参考锚点。

## 5. 人类听感原则

人类听感可以作为 sanity check，但不能作为主要 ground truth。MRS 的主标准应来自数学、物理、声学和信号处理。

## 6. 抗作弊原则

MRS 必须防止以下伪提升：

- 只提高响度；
- 过度提亮；
- 过度压缩；
- 牺牲动态换取表面刺激；
- 破坏高质量样本；
- 空间感贴片化；
- 高频塑料感增强。

## 7. 升级原则

任何 MRS 版本升级必须：

1. 更新版本号；
2. 记录修改原因；
3. 跑验证矩阵；
4. 输出升级前后对比；
5. 写入 Decision Log；
6. 未通过验证不得 ADOPT。
