# Naming Convention｜命名规范

## 节点文件

```text
NEM-<链路编号>-<节点编号>_<English_Name>.md
```

## AEP 文件

```text
AEP-<节点编号>-<序号>_<English_Name>.md
```

## Gate 文件

```text
GATE-<序号>_<English_Name>.md
```

## 报告文件

```text
mrs_run_<date>_<run_id>_summary.md
mrs_validation_<version>_<date>.md
```

## 评分记录

```text
mrs_scores_<run_id>.jsonl
mrs_scores_<run_id>.csv
```
