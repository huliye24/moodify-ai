## 1. AEP 一句话定义

让系统具备基础容错能力，避免单个任务失败导致整轮运行失控。

---

## 2. 为什么需要这个 AEP

该 AEP 是 MT-001 节点的最小工程做功单元之一。  
它的目标不是写一段孤立代码，而是让 Runtime 云端系统具备一个可验证、可复盘、可升级的基础能力。

---

## 3. 交付物

```json
{
  "task_id": "TASK_xxx",
  "status": "failed",
  "error": "具体错误原因",
  "retry_count": 0
}
```

---

## 4. 验收标准

- 失败任务不会导致整个系统崩溃；
- 失败原因被写入日志；
- 可单独重跑失败任务；
- 可设置最大重试次数；
- 后续支持自动重试。
