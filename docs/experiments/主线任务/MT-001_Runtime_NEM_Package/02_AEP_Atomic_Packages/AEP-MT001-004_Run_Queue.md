# AEP-MT001-004｜任务队列生成系统

所属节点：NEM-MT-001｜Runtime 云端运行系统  
所属项目：Moodify  
AEP 类型：Atomic Engineering Package｜工程原子包  
优先级：P0  
状态：BASIC_DONE  

---

## 1. AEP 一句话定义

从输入样本生成可执行任务队列，使一个样本可以自动扩展为多个 preset 处理任务。

---

## 2. 为什么需要这个 AEP

该 AEP 是 MT-001 节点的最小工程做功单元之一。  
它的目标不是写一段孤立代码，而是让 Runtime 云端系统具备一个可验证、可复盘、可升级的基础能力。

---

## 3. 交付物

```text
run_queue.jsonl
```

---

## 4. 验收标准

- 一个样本可生成多个 preset 任务；
- 每个任务有唯一 task_id；
- pending / running / completed / failed 状态可追踪；
- 可支持 3×3、10×3、30×3 等批量扩展。
