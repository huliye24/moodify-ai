## 1. AEP 一句话定义

建立输入音频样本注册机制，让每个音频都有唯一 ID 和可追踪来源。

---

## 2. 为什么需要这个 AEP

该 AEP 是 MT-001 节点的最小工程做功单元之一。  
它的目标不是写一段孤立代码，而是让 Runtime 云端系统具备一个可验证、可复盘、可升级的基础能力。

---

## 3. 交付物

```text
input_registry.jsonl
```

---

## 4. 验收标准

- 每个音频都有唯一 sample_id；
- 样本路径可追踪；
- 后续结果可以反向关联到原始样本；
- 支持真实 AI 音乐样本扩容。
