## 1. AEP 一句话定义

建立云端运行配置中心，使 Runtime 修改参数时不需要改主代码。

---

## 2. 为什么需要这个 AEP

该 AEP 是 MT-001 节点的最小工程做功单元之一。  
它的目标不是写一段孤立代码，而是让 Runtime 云端系统具备一个可验证、可复盘、可升级的基础能力。

---

## 3. 交付物

```text
configs/runtime_config.json
```

---

## 4. 验收标准

- 配置文件可被 Runtime 正确读取；
- 配置项含义清晰；
- 修改配置不需要改主代码；
- 支持 MRS 开关、dry-run、输出目录、日志目录等配置。
