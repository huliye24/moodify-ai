## 1. AEP 一句话定义

让 Moodify 可以在云端后台自动运行，不依赖 AI 或人工持续监视。

---

## 2. 为什么需要这个 AEP

该 AEP 是 MT-001 节点的最小工程做功单元之一。  
它的目标不是写一段孤立代码，而是让 Runtime 云端系统具备一个可验证、可复盘、可升级的基础能力。

---

## 3. 交付物

```bash
nohup python3 scripts/day_run_24h.py > logs/day_run_001.log 2>&1 &
```

---

## 4. 验收标准

- 脚本可在后台运行；
- 关闭终端后任务不中断；
- 可通过 PID 查看进程；
- 可通过日志查看进度；
- 运行结束后自动停止。
