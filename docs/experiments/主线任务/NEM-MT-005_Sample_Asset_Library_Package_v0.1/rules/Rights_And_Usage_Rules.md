# Rights and Usage Rules

MT-005 必须把权限状态作为样本资产的一部分。

## 权限状态

- internal_research_only
- user_owned
- public_domain
- licensed
- uncertain
- restricted

## 使用边界

- internal_research_only：可用于内部研究、调试、MRS 验证和 preset 评估。
- uncertain：只能保留为临时检查样本，不可进入公开演示、商业测试、训练数据。
- restricted：不能继续使用。
- user_owned / licensed / public_domain：按具体授权范围使用。

## 必须记录

- rights_status
- rights_note
- usage_allowed
- usage_forbidden
- reviewed_at
