## 每个 preset 的完整红线（ChatGPT 修正后）

### warm_vocal
```
✓ 人声更温暖、更近、更有厚度
✗ 不能糊、不能轰、齿音不能更明显
✗ 不能像被贴在脸上、不能为了温暖牺牲清晰度
```

### clean_master
```
✓ 几乎听不出变化、频谱更干净
✗ 不能比原版更累耳、不能改变原曲性格
✗ 不能为了干净削弱生命力、不能"响度变大所以误以为更好"
```

### wide_space
```
✓ 空间明显变宽、更有包围感
✗ 低频不能散、中心主体不能塌
✗ 人声不能后退过多、空间不能像贴上去、mono 兼容不能明显变差
```
