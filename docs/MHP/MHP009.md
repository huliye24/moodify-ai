## 工具

Inspector 可以为每一对生成带空白 checklist 的报告：

```bash

  --before tests/baseline/test_audio/vocal_folk.wav \
  --after calibration_reports/v0.1.0-alpha.1-tuning-b/vocal_folk/warm_vocal/vocal_folk_warm_vocal.wav \
```

## 听感 Checklist 评分指南

| 维度 | 1 | 3 | 5 |
|------|---|---|---|
| **Clarity** | 模糊、浑浊 | 可接受 | 清晰、通透 |
| **Warmth** | 冷、薄 | 适中 | 温暖、饱满 |
| **Space** | 扁平、拥挤 | 有空间感 | 开阔、有深度 |
| **Harshness** | 刺耳、尖锐 | 偶尔不适 | 柔和、舒适 |
| **Plastic feel** | 明显塑料感 | 轻微 | 自然、无 AI 痕迹 |
| **Artifacts** | 明显杂音/失真 | 偶有 | 无感知 |

**Better than before?** — 这是最终判决。如果 yes，preset 达到了设计目标。如果 no，需要记录原因。

## 建议测试顺序

不要一次听 9 个。按优先级分批：

### 第一批（必听）：每个 preset × 1 个文件 = 3 对

```
1. vocal_folk + warm_vocal   ← 最关键的测试：warm_vocal 对人声是否真的"温暖增强"
2. piano + clean_master      ← clean_master 对器乐是否"几乎听不出处理痕迹"
3. electronic + wide_space   ← wide_space 对电子乐是否"空间更宽"
```

如果第一批 3 对全部 "Better than before? = yes"，可以认为通过。

### 第二批（补充）：剩余 6 对

交叉验证其他组合。如果第一批都过了，第二批主要是确认没有退化。

## 每个 preset 的验收标准

### warm_vocal

```text
期望：人声更温暖、更亲密、更有厚度
允许：动态适度收紧、声音稍"近"
红线：没有变得更刺耳、没有塑料感、没有明显失真
```

### clean_master

```text
期望：几乎听不出变化，频谱更干净
允许：极其轻微的整体提亮
红线：没有变闷、没有出现 pumping、没有引入 artifacts
```

### wide_space

```text
期望：空间明显变宽，声音更有包围感
允许：主体稍微后退、干湿比变化可感知
红线：没有主体变虚、没有相位问题、没有混响刺耳
```
