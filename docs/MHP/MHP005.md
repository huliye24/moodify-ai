## 1. 项目定位

**Moodify v0.1.0 — AI 音乐二次处理与情绪声波工程系统。**

不是歌词生成器（README 早期版本曾有身份混乱，已修正）。是一个 AI 音乐后期处理引擎：导入音频 → 频谱分析 → 诊断报告 → DSP 预设处理 → 导出优化音频。

技术栈：Python 3.10+ / NumPy / SciPy / librosa / soundfile / pedalboard / FastAPI。

仓库：https://github.com/huliye24/moodify-o3is，tag `v0.1.0-alpha.1`。

## 4. v0.1.0 最小闭环（已验证）

```text
moodify analyze song.wav
    → outputs/song_spectrum.png      ✓

moodify process song.wav --preset warm_vocal
    → outputs/song_warm_vocal.wav    ✓
    → outputs/song_warm_vocal_report.json ✓

curl -X POST http://localhost:8000/process \
  -F "audio=@song.wav" -F "preset=clean_master"
    → 200 audio/wav                   ✓

curl http://localhost:8000/presets
    → 3 presets listed                ✓
```

### 三个预设

| Key | Name | Description |
|-----|------|-------------|
| `warm_vocal` | 温暖人声 | 增强人声温度、厚度和亲密感 |
| `clean_master` | 干净母带 | 透明母带处理，清理频谱 |
| `wide_space` | 宽阔空间 | 增强空间感和听觉宽度 |

每个预设 = 15 个 pedalboard DSP 参数（EQ/压缩/混响/谐波/高频搁架）。
