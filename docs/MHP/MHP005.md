## 当前目标

v0.1.0 的 3 个预设（warm_vocal / clean_master / wide_space）在 API/CLI/测试层面已经跑通，但 **从未用真实音频做过前后对比标定**。

本轮目标不是"新增 preset"，而是 **确认这 3 个 preset 是否真的做到了它们声称的效果**。如果发现参数偏差，微调 DSP 参数。

## 三个预设的设计目标

| Preset | 中文名 | 设计效果 | 关键参数方向 |
|--------|--------|----------|-------------|
| `warm_vocal` | 温暖人声 | 增强人声温度、厚度、亲密感 | 人声 EQ +2.5dB，低频 +2.5dB，轻压缩 2:1，短混响 1.2s |
| `clean_master` | 干净母带 | 透明母带，清理频谱，稳定输出 | 零 EQ，极轻压缩 1.5:1，无混响，无谐波 |
| `wide_space` | 宽阔空间 | 增强空间感和听觉宽度 | 混响 2.5s / 35% wet，宽度 1.0，高频 +2dB |

每个 preset = 15 个 pedalboard DSP 参数（完整参数表见附录）。

## 初步发现（供 ChatGPT 参考，不是结论）

### 发现 1：所有 preset 的 crest factor 下降都偏大

原始 crest factor = 6.50（健康），处理后 warm_vocal = 2.00 / clean_master = 2.75 / wide_space = 2.37。

v01_diagnostics 的诊断阈值是 crest < 2.0 = "over-compressed"。warm_vocal 正好在边界上，wide_space 接近边界。

**即使是 clean_master（"透明母带"），crest 也从 6.50 降到 2.75**。这说明 pedalboard Compressor + Limiter 链在 v01_pipeline 的 pedalboard 处理中始终被激活——即使参数设置为"轻"。

### 发现 2：warm_vocal 的效果方向正确但幅度可能过大

人声频段（presence 2-5kHz）+2.6 dB、低频 +0.7 dB、空气感 +3.0 dB——方向都符合"温暖人声"的设计意图。但 crest 减半可能意味着动态被压得太死，失去了"温暖"应有的呼吸感。

### 发现 3：wide_space 的宽度效果是有效的

Correlation L/R 从 0.838 降到 0.654（↓0.184），说明 M/S 宽度处理在起作用。这是三个 preset 中唯一有明确差异化效果的指标。

### 发现 4：clean_master 最透明但压缩仍然明显

clean_master 的设计意图是"透明母带"，但它仍将 crest 从 6.50 降到 2.75。理想的 clean_master 应该保持 crest 在 4.0 以上。
