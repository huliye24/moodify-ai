## 根因确认

Claude C 审计判定：

> **preset 压缩参数被 pedalboard 链尾 Limiter() 覆盖。所有输出 peak 仍为 -0.0 dBFS。**

`pedalboard_chain.py:91-92`：

```python
board.append(pedalboard.Gain())       # output gain staging
board.append(pedalboard.Limiter())    # safety ceiling
```

ChatGPT 在 MHP-006 中已预判此问题：

> *"如果处理后 peak 仍全部为 -0.0 dBFS，再开 MHP-006-C：只改 Limiter ceiling"*

该条件已触发。
