## 正式听感验收方法

```bash
# 生成 matched 报告（三组）
python scripts/v01_inspector.py \
  --before tests/baseline/test_audio/<file>.wav \
  --after calibration_reports/v0.1.0-alpha.1-tuning-b/<dir>/<preset>/<file>_<preset>.wav \
  --output-dir inspector_reports/<case> \
  --preset <preset> \
  --write-matched-after
```

### A/B 对比方法

```
1. 打开 before 原始 WAV
2. 打开 after_matched.wav（不是未匹配的 processed wav）
3. 同一耳机/音箱，关闭音效
4. 每次只听 20-40 秒关键段落
5. 填写 report.md 中的 Listening Checklist
```

### 验收规则

```
第一批 3/3 Better than before = yes → 进入第二批 6 对
第一批 1 no → 记录原因，重听
第一批 2+ no → 暂停封板，回 ChatGPT

第二批 9 对全部：
  每 preset ≥ 2/3 yes + 无红线 → 该 preset 听感通过
  某 preset 2/3 no 或同一问题重复 2+ 次 → MHP-012 二轮定位
```
