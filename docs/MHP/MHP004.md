## conftest.py（可复用 fixtures）

```python
import numpy as np
import pytest

@pytest.fixture
def mock_audio():
    """10-second 440Hz+554Hz stereo sine at 44100 Hz."""
    sr = 44100
    t = np.arange(sr * 10) / sr
    left = 0.3 * np.sin(2 * np.pi * 440 * t)
    right = 0.3 * np.sin(2 * np.pi * 554 * t)
    return np.stack([left, right], axis=1).astype(np.float32), sr

@pytest.fixture
def mock_wav(tmp_path, mock_audio):
    """Write mock_audio to a temp WAV file."""
    import soundfile as sf
    audio, sr = mock_audio
    path = tmp_path / "test.wav"
    sf.write(str(path), audio, sr)
    return str(path)
```

`mock_wav` fixture 可直接用于 v01 测试——生成临时 WAV → `v01_analyzer.analyze()` → 验证 `AudioMetrics`。

## Claude A 判断

### 1. v01 测试优先级

v0.1.0 闭环是 `导入→分析→诊断→处理→导出`，对应的测试优先级：

| 优先级 | 模块 | 原因 |
|--------|------|------|
| **P0** | v01_pipeline | 端到端闭环，一测顶五 |
| **P1** | v01_analyzer | 核心分析逻辑 |
| **P1** | v01_diagnostics | 诊断规则是否正确触发 |
| **P2** | v01_presets | 3 个预设的 15 参数完整性 |
| **P2** | v01_exporter | WAV 导出 + 限幅 |
| **P3** | v01_types | 序列化往返 |

### 2. 旧测试不需要删除

当前 84 个测试全部通过。按 MHP-001 的"分层冻结"策略，它们属于旧系统测试，不应删除——只要不改旧代码，它们会一直绿。

但需要给它们加一个 pytest marker 区分 v01 和 experimental：

```ini
# pyproject.toml
markers = [
    "v01: v0.1.0 mainline tests",
    "legacy: old system tests (diagnosis/data_types/fallback)",
    "experimental: future modules (uncertainty/fingerprint/conservation/physics)",
]
```

### 3. baseline/ 是一个半成品 CI 工具

`run_baseline.py` 做 4 类测试（导入/回退/质量/性能），`check_regression.py` 做退化检测。但它们不在 pytest 收集范围内，且 `check_regression.py` 的 `import_llm` 测试会 import 一个不存在的 `moodify.llm.offline_fallback`。
