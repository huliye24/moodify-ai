# Moodify UI 草图

这个目录统一存放移动端 UI 草图、截图和交互参考，后续新增图片直接放到对应子目录即可。

## 目录约定

- `references/`：已经确认或正在参考的页面草图。
- `incoming/`：新草图临时放置区，确认后再移动到 `references/`。

## 图标规范

- 以 `references/图标系统-v0.1.png` 为当前图标基准。
- 采用圆角线性图标，常规线宽约 2 px，使用 24 / 28 / 32 dp 规格。
- 默认色使用深海军蓝或灰蓝，选中色使用蓝紫主渐变。
- 品牌主渐变：`#7B61FF → #4A9BFF`。

推荐文件名：`页面-状态-版本.png`，例如 `作品详情-处理完成-v1.png`。
