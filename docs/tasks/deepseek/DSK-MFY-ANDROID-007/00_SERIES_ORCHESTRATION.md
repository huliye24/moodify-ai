## 2. 系列原则（对应电脑端治理）

- **作品是资产**（ADR-003）：SHA-256 全程可校验，不删除、不越权、不泄漏。
- **人保留最终判断**（ADR-001）：A/B 决策工具化，但无自动最终化、无自动评分。
- **无假进度**（002 声明延续）：所有进度来自真实事件或明确"未知"。
- **演示与真实分离**：fake data 只留在占位页，真实流程绝不冒充。
- **失败可审计**（PR-007）：每次失败注入都有记录，禁止静默吞错。
- **电脑端为权威**（023 城门语义）：App 本地是缓存，同步冲突标记不自动覆盖。

## 3. 每包公共约束

- 禁止修改电脑端 Python 业务代码、创建发布密钥、引入未授权第三方依赖。
- 禁止 Git reset/clean/stash/checkout/commit/push。
- 前序门禁必须回归通过；每包交付 PROGRESS/VALIDATION/FAILURE_LEDGER/HANDOFF。
- 最终状态只能是 READY_FOR_CODEX_REVIEW / REWORK / HOLD。
- 真机证据（截图/Logcat/设备信息）优先于 Preview。

## 4. 系列完成定义

与电脑端 API 兼容矩阵文档化 + 已知限制清单如实。
