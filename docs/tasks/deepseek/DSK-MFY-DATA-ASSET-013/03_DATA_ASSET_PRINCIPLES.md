# Moodify 数据资产原则种子

1. 数据文件不是天然资产；只有合法、完整、可追溯、可解释且可用于明确目的的数据才是资产。
2. 权利先于采集，目的限制先于复用，撤回能力先于规模扩张。
3. 上传、处理、试听和发布许可不自动包含模型训练许可。
4. 运营数据、研究证据、候选数据集和获批训练数据必须物理或逻辑隔离。
5. 人工选择及理由比无上下文的文件数量更有研究价值，但不能伪造或反向推断。
6. 每个派生数据都必须能回到源资产、处理版本、参数、人员和权利证据。
7. 删除不只是删除一行；必须能定位派生特征、快照、实验和未来模型影响。
8. Excel 是人工观察层，catalog/manifest 是事实层，音频正文不是默认训练载荷。
9. 数据价值至少由规模、质量、独特性、合法可用性、覆盖度和可学习性共同决定。
10. 数据增长不等于模型进步；只有受控实验和独立评估才能证明学习价值。
11. 用户的同意、退出、导出和删除能力是未来 AI 音乐平台的产品基础，不是附加条款。
12. Moodify 的长期优势来自可合法继承的决策经验，而不是不可解释的数据囤积。
