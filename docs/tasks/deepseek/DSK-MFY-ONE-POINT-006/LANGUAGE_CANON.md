# Language Canon — DSK-MFY-ONE-POINT-006

## Principle

Moodify's default product language must use ≤12 words that every operator can hold in their head. No synonym pairs competing for the same semantic territory. Internal acronyms (WSE/MSE/PPE/MRS) are forbidden from default surface.

## The Twelve Words

### Layer 1: Identity (4 words)

| Word | Meaning | Never confused with |
|---|---|---|
| **Essence** | What the work already is — its given identity | "Quality," "score," "diagnosis" |
| **Protect** | What must survive processing unchanged | "Preset," "constraint," "lock" |
| **Allow** | What may be gently changed | "Enhance," "improve," "fix" |
| **Avoid** | What must not happen | "Risk," "warning," "error" |

### Layer 2: Action & Result (4 words)

| Word | Meaning | Never confused with |
|---|---|---|
| **Refine** | The one action Moodify performs: deliberate, reversible, evidence-backed craft | "Process," "master," "optimize," "enhance" |
| **Evidence** | What the system measured, checked, and recorded | "Data," "metrics," "logs," "scores" |
| **Status** | What state the result is in — never a value judgment | "Grade," "rating," "quality" |
| **Entrust** | What remains for a human to decide — the residual sovereignty | "Pending," "incomplete," "error" |

### Layer 3: Provenance (4 words)

| Word | Meaning | Never confused with |
|---|---|---|
| **Source** | The original material — immutable identity anchor | "Input," "raw," "original" |
| **Candidate** | A version the system prepared for human review | "Output," "result," "final" |
| **Gate** | A technical check that blocks or warns | "Test," "validation," "pass" |
| **Owner** | The human who holds final authority | "Approver," "reviewer," "user" |

## Canonical Phrases

These are the only complete sentences guaranteed to appear in the default surface:

1. **Essence:** _This work is [plain-language description]._
2. **Protect:** _[preserve list] must not be diminished; [avoid list] must not occur._
3. **Allow:** _[list] may be adjusted._
4. **Action:** _Moodify [what was done], based on [evidence type]._
5. **Entrust:** _[what] still requires [Owner]'s judgment._

`Avoid` remains a canonical machine-contract word, but it is nested under
`Protect` on the default human surface. It does not create a sixth narrative
centre.

## Forbidden on Default Surface

- WSE, MSE, PPE, MRS (and any expansion of these acronyms)
- "Improved," "enhanced," "fixed," "better"
- "Score," "rating," "grade"
- "Final" (unless human-declared)
- "Optimized," "automatic," "AI decided"
- "Master," "release-ready," "production-ready"

## Transition Rule

When an internal concept must be surfaced to the operator, it enters through `Evidence` as a progressive disclosure, not through renaming a visible word. This preserves the 12-word contract.
