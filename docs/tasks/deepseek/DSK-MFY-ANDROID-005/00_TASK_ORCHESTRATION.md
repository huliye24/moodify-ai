## 3. 执行阶段

### Stage A｜Media3 播放地基

- 使用 Media3/ExoPlayer 与 MediaSessionService；
- 支持播放、暂停、拖动、耳机键、锁屏和音频焦点；
- App 切后台时播放行为可预测；
- 释放播放器，避免重复实例和资源泄漏。

### Stage B｜公平 A-B

- 原版与处理版共享同一时间位置和播放状态；
- 切换延迟可接受，不从头播放；
- 使用后端提供的响度信息实施可关闭的试听补偿；
- 明确标记当前版本，禁止以更响误导用户；
- 波形只作为导航，不伪装为质量判断。

### Stage C｜版本与决定

- 显示版本号、创建时间、引擎版本、处理摘要和验证状态；
- 接受、要求调整、回退均为追加式决策，不覆盖历史；
- 当前采用版本唯一，回退产生新事件；
- 未验证或 hash 不一致的产物不得接受。

### Stage D｜下载与分享

- 下载可恢复，完成后校验 hash；
- 使用 Android MediaStore/系统选择器保存；
- 通过系统 Sharesheet 分享，不请求不必要权限；
- 文件名安全、不会静默覆盖已有文件。

### Stage E｜真机听感与生命周期

- 有线/蓝牙/扬声器至少覆盖可用设备；
- 锁屏、来电/音频焦点、拔耳机和切后台行为正确；
- 保存一组 A-B 操作录像、播放日志、hash 和决策事件。

## 4. P0 门槛

- 原版/处理版同步位置切换；
