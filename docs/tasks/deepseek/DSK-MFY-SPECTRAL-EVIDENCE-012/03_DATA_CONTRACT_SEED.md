# 数据合同原则种子

1. 每条证据都回答：谁、什么版本、何时、用什么参数测量了哪个输入。
2. `before` 与 `after` 是明确的版本关系，不由文件名猜测。
3. `difference = after - before`，正值只表示该测量维度增加，不表示更好。
4. 原始比较、响度匹配比较和人工试听是三个独立证据层。
5. 缺失、不可用、不适用、失败和真实零值必须区分。
6. 整曲、stem、频带与时间区段共享同一个 case 身份和时间轴合同。
7. 图像服务于观察；结构化数据服务于复核、统计和未来研究。
8. Excel 服务于人；JSON/CSV/Parquet 服务于系统，两者必须同源可追溯。
9. 自动指标不是人工偏好；未试听不是拒绝，未评价不是负样本。
10. 只有有权、可追溯、经人工确认的数据才可能在未来进入训练集。
