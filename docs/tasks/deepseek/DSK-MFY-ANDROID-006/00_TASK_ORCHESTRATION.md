## 1. 目标

冻结第一版范围，在小米真机上完成破坏性场景、性能、隐私和升级验收，交付内部测试版本 `Moodify Android 0.1.0-local-alpha`。本任务只修复 P0/P1，不增加功能。

## 2. 冻结范围

首版仅包含：项目创建、手机音频导入、本地电脑连接、上传、真实任务进度、结果下载、A-B 试听、版本决定、保存分享、连接与诊断设置。

不包含：云账号、支付、合作计划、社区、在线发行、多用户、手机本地完整 DSP、Go Gateway 和正式应用商店发布。

## 4. 验收场景

### Stage A｜安装与升级

- 全新安装、覆盖升级、清除缓存、保留数据升级；
- 版本、API、Engine 不兼容时失败关闭；
- 卸载提示数据影响，不自动删除电脑正式项目。

### Stage B｜完整主链路

- 选择授权测试音频；
- 创建、上传、提交、处理、验证、下载；
- A-B、接受/调整、保存与分享；
- 每一步保存手机与电脑证据。

### Stage C｜故障与 MIUI

- 断 USB、切 Wi-Fi、后台、锁屏、杀 App、重启手机；
- 服务停止、电脑重启、错误端口、磁盘不足、手机低存储；
- 上传中断、处理中断、下载中断、重复点击；
- 失败提示可行动，恢复不重复处理。

### Stage D｜性能与隐私

- 冷启动、内存峰值、上传内存、长时间播放、耗电和温度观察；
- Logcat/服务日志无令牌、原始音频内容、绝对路径和个人数据；
- 权限最小化，无全盘存储、通讯录、位置等无关权限；
- APK 依赖、许可证和已知风险清单。

### Stage E｜封版产物

- 从可复现构建生成内部测试 APK；
- 记录 versionName/versionCode、API 版本、Engine 版本、SHA-256；
- 安装说明、电脑服务启动说明、故障恢复和回滚方案；
- 已知问题按 P0/P1/P2 分类，P0 必须为 0；
- 生成带时间戳的发布 manifest 和项目分析记录。

## 5. P0 门槛

- 干净等价构建与真机安装成功；
- 完整主链路至少连续通过两次；
- 断网、杀 App、电脑服务重启后可恢复且不重复处理；
- P0 已知问题为 0；P1 未解决项必须由用户明确接受；
- 无敏感信息、无越权权限、无原音覆盖；
- APK、SHA-256、版本链、测试证据、安装与回滚文档齐全；
- DeepSeek 只能提交 READY_FOR_CODEX_REVIEW，由 Codex 独立重建和真机复验后写最终 ACCEPT。

## 6. Codex 收尾程序

1. Codex 从源码独立重建 APK；
2. 核对 SHA-256、包名、版本与 API/Engine 兼容；
3. 在小米 10 全新安装并跑两次主链路；
4. 抽查故障恢复、隐私、权限、日志和产物 hash；
5. 复核 P0/P1 清单和用户批准；
6. 写 `CODEX_FINAL_ACCEPTANCE.md`；
7. 在 `project_analytics` 登记封版运行；
8. 未通过则 REWORK，不发布“基本完成”。
