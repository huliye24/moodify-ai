# Principle Seed｜CLI DAW 是可复现的执行系统

1. Moodify 的 DAW 首先是一套声明式工程合同、时间线、处理图和证据系统，不是一扇窗口。
2. 真正的 CLI 意味着没有桌面会话也能完成 probe、plan、render、verify，并给出稳定退出码。
3. Moodify 决定为什么处理、处理什么以及允许多少风险；backend 只执行声明过的动作。
4. NativeDSP + FFmpeg 是最低可靠执行基线；外部 headless 引擎只有经过能力、维护、许可和确定性审计后才能接入。
5. REAPER、Ardour、Audacity 和 Audition 可以服务于导出、兼容与人工精修，但不能成为 Moodify 主流程的事实源。
6. 带命令行参数的 GUI 程序不自动等于 CLI DAW；只要依赖窗口、焦点、弹窗或人工确认，就不能进入无人值守生产路径。
7. 每次运行必须能回答：输入是什么、执行了什么、使用哪个版本、产生什么、如何验证、哪里发生损失。
8. 不支持的能力必须明确拒绝；静默跳过处理比明确失败更危险。
9. 人工听感是独立审批层，不能由技术测试伪造。
10. Moodify 最终应能更换执行引擎而不更换决策合同、项目资产和历史证据。
