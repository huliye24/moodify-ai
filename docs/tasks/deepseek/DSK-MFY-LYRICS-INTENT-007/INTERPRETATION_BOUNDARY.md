# INTERPRETATION_BOUNDARY — DSK-MFY-LYRICS-INTENT-007

## Four-Layer Evidence Discipline

Every claim Moodify makes about lyrics must belong to exactly one layer.

### Layer 1: Source Facts (deterministic, verifiable)

| What | How |
|---|---|
| File path, SHA-256, byte count | Filesystem + hashlib |
| Language code (BCP-47) | Input field; validated format |
| Version enum | Input field; closed set |
| Rights basis enum | Input field; closed set |
| Line count, paragraph count | Deterministic counting (split on `\n\n`) |
| Explicit section labels | Regex match: `^(Verse|Chorus|Bridge|Pre-Chorus|Intro|Outro|Interlude|Hook)` case-insensitive |
| Normalized repeated lines | Strip whitespace, lowercase, SHA-256; count occurrences |
| Declared intent | Echoed verbatim from owner input |

### Layer 2: Human Declarations (always cited)

- `declared_intent` — echoed from input, attributed to `human_owner`
- `must_preserve` / `must_avoid` references to lyrics — attributed to spec author
- NEVER generated by machine

### Layer 3: Limited Inference (must carry basis and uncertainty)

| What is inferred | Basis | Uncertainty statement |
|---|---|---|
| Nothing in Edition 0.1 | — | All inference is deferred. Only source facts + human declarations are produced. |

Edition 0.1 does not perform any inference. The `uncertainties` field always states this explicitly.

### Layer 4: Unknown (preserved as empty, not filled)

| What is unknown | Why it stays unknown |
|---|---|
| Author's true intent | Cannot be deduced from text |
| Sarcasm, irony, persona | Literary devices; not algorithmic failures |
| Emotional state of author | Prohibited inference |
| Political/social stance | Prohibited inference |
| "What the song really means" | Interpretation belongs to humans |

## PROHIBITED Inferences

The following must NEVER appear in any machine-generated output:

1. Psychological claims about the author
2. Identity assertions (gender, age, nationality, etc.)
3. Mental health or medical inferences
4. Political affiliation or social stance
5. "The true meaning of this song is..."
6. Emotional scores or sentiment labels derived from dictionary matching
7. Genre classification from lyrics alone
8. Treatment suggestions derived from lyrical content

## Conflict Handling

When `declared_intent` or `source_facts` reveal tension with the OnePointSpec contract:

1. Record in `conflicts[]` with specific reference
2. Status → `NEEDS_EVIDENCE`
3. Entrust → human_owner
4. NEVER auto-resolve by modifying the spec
5. NEVER rank or prioritize one evidence type over another
