# ADR-MFY-001｜Moodify 听觉智能重分类

**状态：** 已采纳（2026-08-02）
**领域：** WSE + MSE + PPE
**任务包：** DSK-MFY-AUDITORY-INTELLIGENCE-RECLASSIFICATION-001

## 背景

Moodify 历史上以"AI 音乐后处理引擎"为主框架（v01 管线、预设、处理链）。
DSK-MFY-AUDITORY-SCAN-001 建立了听觉扫描与前后对比运行时。本 ADR 将
产品/系统框架从"处理后处理"重分类为"听觉智能"。

## 决策

> Moodify 的核心是听觉观察、表示、判断、验证与学习。处理系统是用于
> 产生受控变化与训练相关证据的干预仪器。

### 之前的主导框架

Moodify 是一个音频后处理系统：输入音频 → 处理 → 输出"更好的"音频。
处理能力即产品身份。

### 新的权威框架

Moodify 是一个听觉智能系统：

- **观察**：声音里发生了什么（扫描、测量、频谱、响度、相位）；
- **表示**：机器如何描述听到的内容（类型化观察、区域、严重度、置信度）；
- **判断**：这是缺陷、风险、有意特征还是未决歧义（技术评估、护栏、请求人耳听音）；
- **验证**：改变了什么、改变了多少、是否达成目标且未造成新损伤（前后对比、证据）；
- **学习**：系统能从该案例学到什么（接受/拒绝候选、成对偏好、人耳标注、数据集资格）。

### 为什么处理仍保留但角色改变

处理（EQ/压缩/限幅/去噪/立体声/相位/音色平衡等）是**受控干预手段**，
用于检验假设、产生候选、生成可对比证据。它不是最终目的——是观察的
触发器与学习的原料。删除处理能力会破坏现有生产与证据历史；保留但
重新定位为**听觉干预实验室（Auditory Intervention Laboratory）**。

### 为什么 Moodify 不做 DAW

DAW 的价值在交互式编辑与实时工作流，是执行面。Moodify 的价值在
听觉智能（判断与学习）。两者不竞争。

### Audacity 的角色

Audacity 是**可接受的外部声音工作台**。Moodify 不自动化 Audacity、
不要求宏、不成为其替代品。外部工具产生候选，Moodify 注册、扫描、
比较、判断、验证。

### Codex / 其他操作者的角色

操作者（Codex、工程师）在干预实验室中执行受控变更，并作为
`processing_operator` 记录在干预记录中。

### 人类艺术审批的角色

技术改进 ≠ 艺术批准。每个对比报告固定包含
`human_listening_required: true` 与 `artistic_approval_granted: false`。
艺术接受只能由人耳听音评估授予。

### 前后证据的角色

before/after 扫描是判断与学习的证据基础：相同不可变 profile、
原始与响度归一化 delta、风险标志、证据 manifest。PNG 是证据视图，
不是规范数值表示。

### 学习记录的角色

案例在提交学习记录前不算"学习完成"。学习记录绑定观察、干预、
对比、人耳评估、成对偏好、权利元数据与数据集资格。资格默认
`UNKNOWN` / `PENDING_REVIEW`，绝不默认 `ELIGIBLE`。

## 后果

正面：

- 产品身份与代码组织对齐（观察/表示/判断/干预/验证/学习边界）；
- 处理能力获得干预实验室的清晰角色，不再被误认为产品核心；
- 学习就绪数据契约建立，为未来训练导出提供受控边界。

负面/风险：

- 迁移期存在双框架表述（旧文档与代码注释仍称"后处理"）；
- 需要维护 inventory 与 migration map 以防分类漂移；
- 学习记录字段较宽，存储与校验成本增加。

## 迁移风险与回滚

- 风险 1：批量重命名破坏公共接口 → **禁止无兼容导入的重命名**；
- 风险 2：学习资格误判导致不合规导出 → **资格默认 UNKNOWN，导出 fail-closed**；
- 风险 3：处理代码被降级导致生产回归 → **只重分类不删除，测试必须保持绿**；
- 回滚：撤销 ADR 采用、保留现有处理路径与案例生命周期不动、删除
  学习/导出新增物即可恢复旧框架（处理能力从未被移除）。

## 被拒方案

- **删除处理代码**：破坏生产与证据历史，拒绝；
- **全库一次性重写**：风险不可控，违反"compatibility first"；
- **Moodify 自己做 DAW**：与定位冲突，拒绝；
- **自动化 Audacity（宏/管道）**：超出本任务范围且不稳定，拒绝；
- **本任务启动模型训练**：仅建立数据契约与受控导出，训练另行立项。
