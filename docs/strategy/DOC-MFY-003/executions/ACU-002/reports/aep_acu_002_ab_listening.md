## 听感测试协议

1. **对比维度：** 音色自然度、频段平衡感、人工痕迹可听性
2. **听音设备：** 录音室监听耳机 / 监听音箱（请在测试时记录具体型号）
3. **测试音频：** AI 生成 3-5 首 + 真实录音 2 首（覆盖不同风格）
4. **EQ 参数组：**
   - **Flat:** 所有 gain = 0 dB（验证透明性）
   - **Moderate:** low_shelf +3 dB @ 200 Hz, peak -2 dB @ 3500 Hz, high_shelf -1.5 dB @ 10 kHz
   - **Extreme:** low_shelf +6 dB @ 200 Hz, peak +4 dB @ 1000 Hz, high_shelf -4 dB @ 6000 Hz
5. **对比方式：** A (legacy FFT) / B (RBJ) 盲听，记录偏好和差异描述

## 预期差异（基于频响曲线分析）

1. **Flat 参数组（0 dB）：** Legacy FFT 和 RBJ 均应完全透明——预期无差异。
2. **Moderate/Extreme 参数组：** RBJ 在 shelf 过渡区的行为更"紧凑"（Q=0.707 ~1 oct），legacy FFT sigmoid 过渡更"宽松"（~0.3 oct）。在高 shelf 和 peaking 场景下，RBJ 的听感应更接近专业 DAW 中的 EQ 行为。
3. **极端参数组：** Legacy Gaussian 在线性频率轴上的对称性在远离 1 kHz 时变得不自然（例如，对 40 Hz 的影响几乎为零，而 RBJ peaking 的 -12 dB/oct 衰减会保留更多低频"余韵"）。
