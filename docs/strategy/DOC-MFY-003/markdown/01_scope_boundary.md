# DOC-MFY-003｜范围边界与不做事项

> 原则：范围边界是项目章程的承重墙。v0.4 的失败模式不是"做得不够"，而是"做进去了不该做的事"。

---

## 1. In Scope（必做）

### 1.1 声学合规修复 (P0)

| 编号 | 条目 | 来源 | 理由 |
|------|------|------|------|
| SCOPE-01 | RBJ biquad EQ 替换 FFT sigmoid/Gaussian EQ | DEF-001 | 滤波器形状不可预测→诊断参数不可跨版本复现。声学合规度的最大单因子拖累 (E_EQ = 0.30) |
| SCOPE-02 | Schroeder 混响全通滤波器级补全 | DEF-002 | 缺少全通级导致混响尾音稀疏→可听伪影。梳状+全通是 Schroeder (1962) 的必要条件 |
| SCOPE-03 | HPSS 残差分量 (Residual) 保留与能量守恒审计 | DOC-MFY-002 新增 | HPSS 分解产生 H+P+R 三个分量。当前丢弃 R→能量不守恒→违反 PHYS-007 |

### 1.2 感知尺度导入 (P1)

| 编号 | 条目 | 来源 | 理由 |
|------|------|------|------|
| SCOPE-04 | 7 频段默认启用并修复 5-8 kHz 空白 | DEF-006 + DOC-MFY-002 新增 | 当前 6 频段在 5-8 kHz 存在分析盲区（Brilliance/齿音区间）。7 频段补全后直接提升诊断覆盖 |
| SCOPE-05 | True Peak Limiter (ITU-R BS.1771) | DEF-001 关联 + NEW-04 | 当前砖墙限幅器使用采样峰值，非真峰值。真峰值过采样 (4x) 可避免 DAC 转换时的片间峰值削波 |
| SCOPE-06 | Mel / Bark / ERB 感知频率尺度分析层 | DEF-005 | 线性 FFT 频率仓不反映人耳频率分辨率。三层感知尺度是 L2 感知层的基础设施 |

### 1.3 实验入口 (P2)

| 编号 | 条目 | 来源 | 理由 |
|------|------|------|------|
| SCOPE-07 | 心理声学掩蔽最小模型 | DEF-004 | 同时掩蔽 + 扩展函数。仅最小实现——不是完整 PEAQ |
| SCOPE-08 | F0 / Pitch Stability 分析入口 | DEF-005 | YIN 算法 + 音高稳定性度量。为 AI 音频特有的 F0 不稳定缺陷提供量化工具 |
| SCOPE-09 | Chroma / Key / Harmony 分析入口 | DEF-005 | 12 维 chroma + 调性检测。为 AI 音频的和声一致性提供量化工具 |
| SCOPE-10 | MRS 参考集鲁棒化 | DOC-MFY-002 新增 | 分风格参考分布 + 非正态鲁棒评分 + 置信区间。解决当前 MRS 参考分布"通用但不精确"的问题 |

## 4. 范围变更控制

### 4.1 变更原则

1. **任何 SCOPE 新增必须先进入候选池，不得直接加入 v0.4。**
2. **P0 修复不可削减。** 如果时间不够，削减 P2，不削减 P0。
3. **范围蔓延的唯一合法理由：** 发现新的 P0 级声学合规缺陷（即"不修复则发布不安全"）。

### 4.2 变更流程

```text
提出变更 → 评估优先级 (P0/P1/P2) → 
  若 P0: 自动纳入，M6 封口日期顺延
  若 P1: CTO 批准后纳入，评估 M4 日期影响
  若 P2: 进入候选池 (POOL-XX)，不在 v0.4 执行
```

---

## 5. 不做事项的积极意义

v0.4 的范围克制不是资源不足，是战略选择：

1. **声学合规是地基。** 地基不牢，上层（感知模型、智能映射、大模型训练）都是沙上建塔。
2. **P0 修复是阻塞项。** 在 EQ 滤波器不可预测的状态下做任何感知实验，数据都无法复现。
3. **v0.4 的成功为 v0.5 铺路。** 合规层修复完成后，v0.5 可以直接进入 PEAQ、Kalman、立体声混响等感知和智能层的建设。
