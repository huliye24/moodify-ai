## 硬件扩张路线图

### 第一阶段：GPU 升级 (2026 Q3-Q4)

**目标**：将 GPU 实验吞吐量提升 4-8 倍

| 选项 | 规格 | 成本估计 | 优势 | 劣势 |
|------|------|----------|------|------|
| A. 云 GPU 租用 | A100 40GB (按需) | ~$1.5/h | 零 upfront 成本，弹性 | 长期成本高，数据传输延迟 |
| B. 本地 RTX 4090 | 24GB VRAM | ~$2,000 (一次性) | 24/7 可用，零运营成本 | VRAM 仍受限，功耗高 |
| C. 云 GPU 预留实例 | A100 80GB (包月) | ~$1,500/月 | 大 VRAM 可训练模型 | 月度固定成本 |

**推荐**：短期用 A (云 GPU 按需) 处理峰值负载，中期评估 B (RTX 4090) 作为日常实验主力。如果 M4 模型训练需要 > 24GB VRAM，必须选 C。

### 第二阶段：声学测量硬件 (2027 H1)

**目标**：建立可重复的声学测量基线

| 设备 | 用途 | 成本估计 |
|------|------|----------|
| 标定麦克风 (如 miniDSP UMIK-1) | 客观的监听环境校准 | ~$100 |
| 音频接口 (如 Focusrite Scarlett) | 低延迟、低噪声的播放/录制 | ~$200 |
| 监听耳机 (如 Sennheiser HD 650) | 主观听感测试标准化的换能器 | ~$400 |
| 监听音箱 (如 Kali LP-6) | 近场监听 | ~$400/对 |

> 注意：此阶段不需要消声室——近场监听 + 标定麦克风 + 室内脉冲响应测量可以补偿房间声学的大部分影响。

### 第三阶段：专用推理硬件 (2027 H2 – 2028)

**目标**：将 Moodify 处理管线部署到专用硬件

| 选项 | 适用场景 | 成熟度 |
|------|----------|--------|
| NVIDIA Jetson Orin | 边缘推理 — 嵌入式音频处理 | 商用现货 |
| FPGA (Xilinx Versal) | 超低延迟 DSP 管线 | 需要 HDL 开发 |
| 定制 ASIC | 大规模部署的终极方案 | 需要 2-3 年 + $5M+ |

**当前判断**：ASIC 在 2030 年前不现实。Jetson Orin 是最可行的"专用推理硬件"入口——可将处理管线容器化部署在边缘设备，实现低延迟的本地处理。

## Scanbox 路线图 (音频扫描自动化)

Scanbox 概念：自动化音频批量扫描 → 诊断 → 分类 → 入库的流水线。

| 阶段 | 能力 | 硬件需求 | 预计吞吐量 |
|------|------|----------|-----------|
| Scanbox v0.1 (当前) | 单文件扫描 + MRS 计算 | CPU | ~10 首/小时 |
| Scanbox v0.2 (2026 Q4) | 批量扫描 + 自动分类 + 缺陷标记 | CPU + GPU (特征提取) | ~50 首/小时 |
| Scanbox v0.3 (2027 H1) | 持续监控 + 新缺陷自动发现 + 参考分布在线更新 | CPU + GPU + 大存储 | ~100 首/小时 |
| Scanbox v1.0 (2027 H2) | 多平台 (Suno/Udio/自有) API 集成 + 全自动扫描到报告 | 云端部署 | ~500 首/小时 |
