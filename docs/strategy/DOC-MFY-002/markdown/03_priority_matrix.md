# T3｜优先级矩阵

> 评分维度：声音影响 (Sound Impact, 1-10)、工程风险 (Engineering Risk, 1-10)、修复难度 (Fix Complexity, 1-10)、战略价值 (Strategic Value, 1-10)
> 优先级公式：Priority = (Sound_Impact × 0.4 + Strategic_Value × 0.3) / (Fix_Complexity × 0.2 + Engineering_Risk × 0.1)
> P0 = Priority ≥ 2.5 | P1 = 1.5 ≤ Priority < 2.5 | P2 = Priority < 1.5

## 声音影响评分细则

| 分数 | 标准 | 对应缺陷 |
|------|------|----------|
| 8-10 | 直接影响最终音频的可听质量——用户能听出问题 | DEF-001 (EQ 形状不可预测) |
| 6-7 | 显著影响特定场景的处理质量 | DEF-002 (混响尾音), DEF-005 (AI 和声缺陷) |
| 4-5 | 影响分析精度或诊断一致性 | DEF-004 (掩蔽), DEF-006 (频段) |
| 2-3 | 边际改善——多数场景下差异不可听 | DEF-007/008/009 |
| 1 | 理论完善，对当前音频质量影响极小 | DEF-013 |

## 建议执行顺序

```text
第一梯队 (立即执行, 预计 1-2 周):
  DEF-001 (RBJ EQ 替换) ── 声音影响最大，修复难度最低
  DEF-006 (频段统一) ── 修复最简单，消除系统性的诊断不一致

第二梯队 (短期, 预计 2-4 周):
  DEF-002 (全通滤波器) ── 声音影响大，实现难度中等
  DEF-005 (mel/bark/chroma/F0) ── 为后续 PEAQ/掩蔽模型提供基础特征

第三梯队 (中期, 预计 1-3 月):
  DEF-004 (掩蔽模型) ── 为 PEAQ 提供基础
  DEF-003 (PEAQ 模型) ── 长期战略价值最高
  DEF-008 (立体声混响) ── 改善空间处理
  DEF-009 (stereo-link) ── 改善动态处理

第四梯队 (长期, 预计 3-6 月):
  DEF-007 (粗糙度标准) ── 学术完善
  DEF-011 (HPSS 自适应) ── 工程优化
  DEF-012 (贝叶斯校准) ── 模型升级
  DEF-013 (情绪维度) ── 理论扩展
  DEF-010 (听感测试) ── 组织建设——持续进行，非一次性任务
```
