# T4｜三层声学研发模型

> 核心判断：Moodify 的声学处理体系应按"合规→感知→智能"三层递进建设。当前 v0.1.0 在合规层完成度最高 (~70%)，感知层起步 (~20%)，智能层尚未开始 (~0%)。

## L1: 声学合规层 (Acoustic Compliance Layer)

### 定义

确保每一个声学处理模块符合行业标准的理论要求。这一层不追求创新——它的目标是"如果教科书说这样做，Moodify 就必须这样做"。

### 范围

| 子模块 | 标准/参考 | 当前状态 | 目标状态 |
|--------|----------|----------|----------|
| 滤波器设计 | RBJ Audio EQ Cookbook (R10) | FFT sigmoid/Gaussian 近似 — 不合规 | 全线 RBJ biquad (pedalboard 主路径 + 自定义实现备路径) |
| 人工混响 | Schroeder (1962) (R09) | 梳状滤波器仅 + 单声道输入 — 部分合规 | 梳状 + 全通 + 双声道独立处理 |
| 响度测量 | ITU-R BS.1770-5 (R06) | pyloudnorm 集成 — 完全合规 | 维持，添加真峰值 (True Peak) 过采样测量 |
| 响度范围 | EBU Tech 3342 (R07) | 3 秒块 + 百分位法 — 完全合规 | 维持 |
| 频段定义 | Zwicker & Fastl (2007) Bark 尺度 | 6 频段，但与标准 Bark 尺度存在偏差 — 部分合规 | 统一频段 + 添加 Bark 尺度映射 |
| 频谱分析 | FFT (通用 DSP) | 标准 FFT — 合规 | 添加感知加权频谱 (A/C/K-weighting) |
| 能量守恒 | PHYS-007 (自研) | 三级审计 — 合规且创新 | 扩展到动态范围和相位守恒的全维度审计 |
| 动态处理 | 前馈 RMS 压缩器 (通用) | 基本实现 — 合规 | 添加 stereo-link 控制、前瞻 (lookahead) 功能 |
| 峰值控制 | 砖墙限幅器 (通用) | 基本实现 — 合规 | 添加真峰值 (True Peak) 限幅 |
| 立体声处理 | M/S 立体声宽度 (通用) | 基本实现 — 合规 | 添加相位相关性监控 |

### 合规评分

```text
A_compliance = L_loudness × E_EQ × R_reverb × H_HPSS × P_peak × C_conservation

当前值:
  L_loudness = 0.95 (LUFS + LRA 完全合规)
  E_EQ       = 0.30 (FFT EQ 非标准 — DEF-001 修复后升至 0.90)
  R_reverb   = 0.40 (缺全通级 + 单声道 — DEF-002/008 修复后升至 0.85)
  H_HPSS     = 0.85 (标准 HPSS，margin 自适应可提升至 0.90)
  P_peak     = 0.75 (砖墙限幅器功能正确，但缺真峰值过采样)
  C_conservation = 0.90 (能量守恒审计完善)

A_compliance = 0.95 × 0.30 × 0.40 × 0.85 × 0.75 × 0.90 = 0.065
→ 归一化到 [0,100]: 65/100

目标 (DEF-001/002/008 修复后):
  A_compliance = 0.95 × 0.90 × 0.85 × 0.90 × 0.75 × 0.90 = 0.443
→ 88/100
```

- `ENG-MFY-006`: 频段定义统一

## L2: 感知声学层 (Perceptual Acoustics Layer)

### 定义

在 L1（物理正确）基础上，确保系统处理的输出在**人耳听起来**是正确的。这一层引入心理声学模型——频率掩蔽、时间掩蔽、响度感知、粗糙度、感知音频质量。

### 范围

| 子模块 | 标准/参考 | 当前状态 | 目标状态 |
|--------|----------|----------|----------|
| 频率掩蔽模型 | Zwicker & Fastl (2007) 第 7-8 章 | 未实现 | 扩展函数 (spreading function) + 掩蔽阈值计算 |
| 感知音频质量 | ITU-R BS.1387-2 PEAQ (R08) | 未实现 | PEAQ Basic (FFT-based ear model) |
| 频谱粗糙度 | Vassilakis (2007) (R20) | 卷积局部方差代理 — 非标准 | 标准 Vassilakis 粗糙度模型 |
| Bark 尺度映射 | Zwicker (1961) | 未实现 | FFT → Bark 尺度频率映射 |
| Mel 尺度特征 | MFCC (R13) | 未实现 | 13 维 MFCC + Δ + ΔΔ |
| Chroma 特征 | Chroma (R13) | 未实现 | 12 维 chroma + chroma 稳定性 |
| F0 基频检测 | YIN (de Cheveigné & Kawahara 2002) | 未实现 | F0 轨迹 + F0 稳定性 |
| 响度感知模型 | Zwicker loudness (ISO 532B) | 仅 LUFS (广播标准，非感知模型) | 添加 Zwicker 响度模型（时变特定响度） |
| 空间感知 | 耳间互相关系数 IACC, 双耳响度 | 未实现 | IACC 频率曲线 + 感知声源宽度 (ASW) |

### 感知对齐评分

```text
P_align = M_mel × B_bark × E_ERB × K_masking × F_F0 × C_chroma

当前值:
  M_mel      = 0.00 (无 mel 特征)
  B_bark     = 0.00 (无 Bark 尺度映射)
  E_ERB      = 0.00 (无 ERB 滤波器组)
  K_masking  = 0.00 (无掩蔽模型)
  F_F0       = 0.00 (无 F0 检测)
  C_chroma   = 0.00 (无 chroma 特征)

P_align = 0.00 → 0/100

第一阶段目标 (DEF-005 完成后):
  M_mel  = 0.80, B_bark = 0.70, C_chroma = 0.70, F_F0 = 0.80
  P_align = 0.80 × 0.70 × 0 × 0 × 0.80 × 0.70 = 0 → 仍为 0 (掩蔽和 ERB 未实现)

第二阶段目标 (DEF-004 完成后):
  K_masking = 0.70, E_ERB = 0.60
  P_align = 0.80 × 0.70 × 0.60 × 0.70 × 0.80 × 0.70 = 0.132 → 13/100

第三阶段目标 (DEF-003/007 完成后):
  各因子升至 0.85+
  P_align = 0.85^6 = 0.377 → 38/100
```

> **注意**：P_align 的乘积结构意味着感知层的建设是"全有或全无"的——缺少任一项，总分归零。这反映了感知声学的现实：如果不知道人耳对不同频率的敏感度差异 (Bark/ERB)，mel 特征本身的价值有限。

- `EXP-MFY-004`: 频率掩蔽模型实验
- `EXP-MFY-005`: mel/bark/chroma/F0 特征提取与验证

## L3: 音乐智能层 (Music Intelligence Layer)

### 定义

在 L1（物理正确）和 L2（感知正确）基础上，使系统能够理解音乐的**情感语义**、**风格特征**和**审美标准**。这一层是 Moodify 最独特的层——它将声学处理从"信号处理"提升为"音乐理解"。

### 范围

| 子模块 | 理论依据 | 当前状态 | 目标状态 |
|--------|----------|----------|----------|
| 情绪→参数映射 | 8 情绪原型 (自研) | craft_chains 完整 — 业界领先 | 扩展到 VA 连续维度空间 (DEF-013) |
| 工艺推荐 | T_EFFECTS + B 矩阵 (自研) | 线性代理模型 + 岭回归 — 工作中 | Kalman filter 贝叶斯校准 (DEF-012) |
| AI 评委 | 三评委评估 (自研) | DeepSeek + 客观指标 — 工作中 | 人类评委校准曲线 (DEF-010) |
| 风格感知 | 音乐类型/流派分类 | 未实现 | 流派分类器 → 流派特异性工艺链 |
| 结构感知 | 音乐段落检测 (verse/chorus/bridge) | 未实现 | 结构分段 → 段落特异性处理 |
| 审美学习 | 从专家反馈中学习审美偏好 | 未实现 | 工艺链参数的强化学习优化 |
| 多模态理解 | 歌词→情绪→声学处理的桥接 | 未实现 | 歌词情感分析 → 工艺链选择 |

### 当前完成度

L3 已实现的核心能力（`craft_chains.py`、`emotion_targets.py`、`evaluation/judges.py`、`llm/client.py`）构成了音乐智能的基础——离散情绪到声学参数的映射。这些已达到业界领先水平（见 S-006、S-011）。

但 L3 的扩展方向（连续情绪空间、风格感知、结构感知、审美学习）全部在规划阶段。

## 分层交互关系

```text
L3 音乐智能层
  │  依赖 L2 提供感知有效的特征
  │  依赖 L1 提供物理正确的处理
  │
  ▼
L2 感知声学层
  │  依赖 L1 提供无伪影的物理信号
  │  为 L3 提供感知加权的特征表示
  │
  ▼
L1 声学合规层
  │  为 L2/L3 提供正确的信号处理基础
  │  独立于 L2/L3 可验证（纯物理标准）
```

**关键约束**：
- L1 的错误（如非标准 EQ）会在 L2 和 L3 中放大——基于错误信号特征的感知判断和智能决策都会偏离
- L2 的缺失（如无掩蔽模型）不会使 L1 错误，但会使 L3 的"智能"其实不知道人耳听到了什么
- L3 的创新（如情绪映射）是最难复制的资产——但其可靠性取决于 L1 和 L2 的坚实基础
