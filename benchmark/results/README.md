# Results Directory

This directory contains benchmark evaluation results.

## Structure

```
results/
├── README.md
├── baseline_results.json           # Latest baseline evaluation
├── comparative/
│   └── model_comparison_*.json   # Model comparison results
└── historical/
    └── YYYY-MM-DD/                # Archived results by date
```

## Result Files

Result files follow the schema defined in `../evaluation_protocol.md`.

### Baseline Results

Generated by: `python ../baseline.py batch -d <dataset> -o results/`

### Comparative Results

Model comparison results include:

- Model identifiers
- Evaluation timestamps
- Statistical comparisons
- Confidence intervals

## Data Retention

- Active results: Kept in root of `results/`
- Historical results: Archived by date
- Large result sets: May be stored externally with links

## Privacy

- Human ratings are anonymized
- No personally identifiable information
- Aggregated statistics only
