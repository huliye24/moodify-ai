# Moodify 三个生产研究问题

**Status:** EXPERIMENTAL RESEARCH FRAMEWORK  
**Date:** 2026-10-12  
**Canon change:** NO  
**Authority:** 本文组织研究问题与证据，不建立第二套 Core、Judge 或生产状态机。

## 研究命题

在 AI 音乐完成阶段，Moodify 当前把研究收敛为三个相互依赖、但必须分别归因的问题：

1. **怎么让人声更真？**（Vocal Authenticity）
2. **怎么让伴奏更顺？**（Accompaniment Coherence）
3. **怎么通过修音与混音把材料完成为作品？**（Production Completion）

三者不是三个产品或三套评分系统。它们是同一个 Moodify Core 和同一个 Judge 下的三个证据域。最终判断始终是：在保护作品身份和意图的前提下，新候选相对当前基准是否获得了可验证的净收益。

```text
Vocal Authenticity
        ↓
Accompaniment Coherence
        ↓
Production Completion
        ↓
Technical Verification
        ↓
Loudness-matched Blind Comparison
        ↓
ACCEPT / RETRY / KEEP ORIGINAL
```

该顺序表示默认研究和处理优先级，不表示三个问题只能串行发生。混音暴露的人声或伴奏问题可以回流到前一层，但每次实验必须保持原因和改动可归因。

## RQ1：怎么让人声更真？

### 研究对象

人声真实性不是“音准正确”的同义词，而是演唱身份与表演连续性的综合结果：

- 音高过渡、滑音、颤音及换声是否自然；
- 辅音、元音、咬字和音素时长是否连续；
- 呼吸、齿音、爆破音、尾音是否符合真实发声；
- 音色是否随音高、力度和元音发生可信变化；
- 乐句力度、节奏微偏移和情绪是否构成完整表演；
- 修复或重建后，原有歌手身份是否仍被保留；
- 分离残留、生成伪影和局部断裂是否造成“假感”。

### 第一原则

**直接分析可信的人声分轨，完整混音只用于上下文和归因。** 相对 `V − A` 异常必须拆分人声侧与伴奏侧贡献，不能直接触发人声修复。

### 实验循环

```text
人声分轨检测
→ 局部异常定位
→ 原因归因
→ 单一局部挑战者
→ 身份与表演保护检查
→ 回混复检
→ 匿名盲比
```

### 可测证据

- F0 连续性、音高偏差及过渡形态；
- 音符/音素起止与节奏偏差；
- 电平、crest、局部动态和掉点；
- 谐噪比、周期性、频谱包络和音色漂移；
- 齿音、爆破音、呼吸和辅音瞬态；
- 接缝、相位、背景泄漏和分离伪影；
- 处理前后歌手身份相似性；
- 经过校准的真实性/自然度听感响应。

### 证据边界

任何单项技术指标都不能独立证明“更真”。音高更准可能让表演更假；音色相似也不等于表达自然。未经真实匿名听感数据校准的模型评分必须标记为实验性。

## RQ2：怎么让伴奏更顺？

### 研究对象

伴奏连贯性不是“乐器音色高级”，而是音乐事件随时间和结构自然运动：

- 乐器进入、退出、转场和尾音是否连续；
- 鼓、低音、和声与旋律层之间是否时间一致；
- 生成或分离后的乐器轨是否存在断裂、泄漏和残留；
- 编曲密度和能量是否随段落合理发展；
- 人声出现时，伴奏是否让出必要的频谱、动态和空间位置；
- 低频、节奏重心与和声变化是否稳定支撑歌曲；
- 局部重建是否引入不可解释的音色或空间跳变。

### 第一原则

**“顺”必须同时在时间、频谱、结构和上下文中验证。** 全曲固定 EQ、压缩或立体声宽度不能替代逐事件诊断。

### 实验循环

```text
结构与事件检测
→ 断裂/遮蔽/转场定位
→ 确认责任分轨
→ 单事件最小干预
→ 分轨复合
→ 上下文与跨设备复检
→ 匿名盲比
```

### 可测证据

- onset/offset、节拍和微时序偏差；
- 分轨重组可逆性与残差信号；
- 局部频谱跳变、能量斜率和遮蔽；
- 乐器进入/退出前后的响度及动态连续性；
- 低频稳定性、声像和相干性；
- 段落密度、重复与对比关系；
- 手机、耳机、小音箱和单声道可译性。

### 证据边界

电子或合成乐器可以在风格上成立，但这不意味着伴奏天然无问题。音色可替换不等于节奏、和声、编排和空间关系可以忽略。

## RQ3：怎么通过修音与混音完成作品？

### 研究对象

作品完成度回答的是：前两层材料如何被组织成一个可信、可交付、可回退的完整结果。

- 主唱、伴唱与伴奏的逐句平衡；
- 遮蔽控制和频谱角色分配；
- 动态、纵深、混响、延时与立体声场；
- 局部自动化和段落情绪曲线；
- 接缝、爆音、淡入淡出与混响尾部；
- 不同播放环境中的可译性；
- 响度、真峰、编码和交付格式；
- Mix Graph、参数、证据与回退路径是否齐全。

### 第一原则

**完成不是再跑一次全局算法，而是把已经定位的问题逐个解决，并证明没有破坏受保护特征。** 技术合规是交付地板，不是作品质量的充分条件。

### 实验循环

```text
当前基准
→ 选择一个证据充分的问题
→ 生成一个局部挑战者
→ 重组完整作品
→ 技术复检
→ 严格响度匹配
→ 匿名 A/B
→ 挑战者成为新基准或保留原版
```

### 可测证据

- 逐句 vocal/accompaniment balance 及其两侧归因；
- 局部遮蔽、动态、响度、真峰、LRA、PLR；
- Mid/Side、相关性、单声道折叠和空间连续性；
- 接缝、点击、削波、尾部和静音异常；
- 分轨处理前后与最终复合结果的可归因差异；
- 统一条件下的匿名可辨认度、偏好和损害报告。

### 证据边界

交付合规不能证明作品更好；机器评分不能在未经校准时替代审美权威。结果不明确、越界或局部受损时，必须进入 `HUMAN_REQUIRED`、`INCONCLUSIVE` 或 `KEEP_ORIGINAL`。

## 三个研究域的统一记录

每次实验至少记录：

| 字段 | 要求 |
|---|---|
| `research_question` | `VOCAL_AUTHENTICITY` / `ACCOMPANIMENT_COHERENCE` / `PRODUCTION_COMPLETION` |
| `case_id` | 当前歌曲与生产 case |
| `time_range` | 明确的局部时间范围 |
| `evidence` | 触发实验的测量、图表和试听依据 |
| `hypothesis` | 本轮只验证的一个原因假设 |
| `preserve` | 歌词、旋律、节奏、身份、表达或其他保护目标 |
| `provider` | 使用的处理 Provider、版本、模型和权重哈希 |
| `parameters` | 完整可复现参数 |
| `verification` | 处理后技术复检与失败项 |
| `blind_comparison` | 响度匹配、匿名映射、响应与置信度 |
| `decision` | `ACCEPT` / `RETRY` / `KEEP_ORIGINAL` / `HUMAN_REQUIRED` |

## 研究规则

1. 固定的是流程、证据契约、门禁和裁决规则，不是调音参数。
2. 每次只处理一个边界清楚的问题，生成一个挑战者。
3. 人声、伴奏、复合三个层面的改动必须分别归因。
4. 分轨重组可逆性不通过，不得开始逐轨处理。
5. Provider 只负责执行；Moodify Judge 负责前置理由与后置验收。
6. 未经校准的指标不能被宣传为作品质量真值。
7. `Generated is not finished.` 同样适用于模型输出、实验图和候选音频。
8. 没有明确净收益时保留原版。

## 当前实验映射

- S011：暴露 `V − A` 将人声与伴奏原因混合的问题。
- S012：转向人声分轨内部诊断，定位人声侧独立异常候选。
- S013：应针对一个原因明确的局部人声问题生成单一挑战者，并完成保护检查与盲比。
- 后续伴奏实验：应建立逐事件连续性、转场和遮蔽诊断，而非复用人声电平规则。
- 后续作品完成实验：只接收前两层已有证据的处理结果，负责复合、复检和最终选择。

## 当前状态

这是实验研究框架，不是已校准模型。三个领域的统一 schema、生产阈值和学习型 Judge 均未因本文而自动实现。
