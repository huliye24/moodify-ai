# Canonical Local Execution Graph

`decoded_audio -> global_measurements`

`decoded_audio -> auditory_representation`

`decoded_audio -> temporal_events`

`global_measurements + temporal_events -> judgment`

`decoded_audio + representation + events + judgment -> evidence_bundle`

`measurements + events + judgment + evidence -> report`

The graph schedules existing auditory authorities. It does not define new metrics or event classes.
