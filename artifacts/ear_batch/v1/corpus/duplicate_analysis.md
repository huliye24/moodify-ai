# Duplicate Source Analysis — Chapters 02–04

The extra top-level Chapter 02, 03, and 04 directories are exact duplicates of
the corresponding extracted package trees. SHA-256 comparison covered each
chapter's manifest, monograph Markdown, PDF, README, and references file: all
15 comparisons were byte-identical.

For consistent traversal with Chapters 05–20, the extracted tree below each
`Moodify_Ear_v1_Chapter_NN_Package` directory is selected as the authoritative
input. The additional top-level directory remains untouched as provenance and
is excluded from normalized traversal. ZIP files remain distribution artifacts,
not a second content authority.

This decision requires no scholarly or architecture judgment because the
candidate files are byte-identical. Any future hash difference invalidates the
decision and must reopen human review.
