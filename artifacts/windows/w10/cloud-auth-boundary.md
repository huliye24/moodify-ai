# Cloud Authentication Boundary

The desktop client stores only an in-memory bearer token interface. The deployed media upload route is guarded by invite-beta account capability plus server session cookie/CSRF behavior; live bootstrap reports writes disabled. No safe desktop user-auth flow for preparation exists.

`CLIENT_AUTH_BLOCKED = YES`. W10 will not embed service keys, database credentials, internal auditory credentials, third-party provider secrets or infrastructure tokens. Acceptable unblock mechanisms are a real user session plus CSRF-safe desktop contract or backend-issued scoped short-lived upload/source credentials.
