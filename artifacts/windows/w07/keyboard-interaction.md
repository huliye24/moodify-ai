# Keyboard Interaction

Within Library views: Enter plays focused Track, Ctrl+A selects visible Tracks, Escape clears selection/menu, Delete or Backspace requests scoped Library removal. Space remains the existing play/pause command only when focus is not inside input, textarea, select, button, contenteditable, dialog or menu. This prevents typing/forms/context menus from triggering playback.

No new global/native shortcuts were added.
