# W02-P01 Input Contract

## Required from W02-P00

- Current Reality Revalidation
- Riverbed Capitalization Check
- Regression & Drift Report
- Current Debt & Unknowns
- Wave 02 Candidates
- Human Selection Gate
- Selected Wave 02 Problem
- W02-P00 Acceptance Report

## Required Human State

Exactly one candidate selected.

## Required Problem Evidence

At least:

- one current W02 reality observation
- one measurable baseline or a clear measurement gap
- one explicit user/main-river impact

## Hard Stop

- no human selection
- no current evidence
- candidate is only a technology noun
- success cannot be measured
