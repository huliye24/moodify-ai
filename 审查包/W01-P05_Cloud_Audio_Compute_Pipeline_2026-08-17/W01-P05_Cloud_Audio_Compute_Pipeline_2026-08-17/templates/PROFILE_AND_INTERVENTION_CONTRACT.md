- profile_id
- profile_version
- description
- compatibility
- parameter/chain manifest hash
- created_at
- authority

## Decision

- source judgment
- selected profile
- selection reason
- evidence
- uncertainty

## Intervention Manifest

- input refs
- output refs
- tool chain
- parameters
- tool versions
- started/finished
- warnings
- evidence

## Rule

Changing effective processing semantics requires a new version identity.
