# W01-P09 — First Cognitive Distillation

这是 **Moodify Cognitive Wave 01 的最后一个任务包**。

## 只有 1 个原子任务

**Wave 01 Cognitive Distillation**

它不继续开发。

它负责把 P00–P08 已经支付过的认知成本变成：

```text
Evidence
→ Observation
→ Lesson
→ Rule
→ SOP
→ Test
→ Tool
→ Infrastructure
```

但不是所有东西都要升到 Infrastructure。

原则是：

> **Minimum Sufficient Distillation**
>
> 用最低的持久层级，永久消除一种重复认知成本。

## 本包最终最重要的三个结果

- 新的 `CURRENT_PROJECT_SNAPSHOT`
- 新的 `AGENT_COLD_START`
- `WAVE_01_CLOSEOUT`

下一位 Agent 应该不看旧对话，也能迅速理解 Moodify 的真实系统、主河道、已知失败与未决问题。

P09 结束后不自动进入 Wave 02。
