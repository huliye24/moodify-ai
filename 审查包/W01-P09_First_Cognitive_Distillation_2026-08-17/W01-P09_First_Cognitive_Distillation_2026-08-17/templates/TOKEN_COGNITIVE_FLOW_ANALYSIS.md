# Token & Cognitive Flow Analysis

## Scope

This is a post-hoc production analysis.

Token is treated as a measurable carrier/cost proxy of machine cognitive activity.

Token is **not** treated as labor value.

## Candidate Waste Categories

- repeated context reconstruction
- repeated authority lookup
- repeated runtime identity lookup
- repeated known-failure diagnosis
- repeated manual evidence assembly
- stale/legacy document misdirection
- duplicate task planning

## Useful Token Expenditure

- genuinely new problem exploration
- evidence inspection
- necessary uncertainty reduction
- safety/security review
- new failure analysis
- architecture decisions supported by new facts

## TMR

If computed, Token Mainstream Ratio is a diagnostic only.

It must not be used as:

- employee KPI
- Agent speed KPI
- optimization target without context
- reason to suppress necessary exploration

## Conclusion

What repeated cognitive costs were eliminated?
What unavoidable/valuable exploration remains?
