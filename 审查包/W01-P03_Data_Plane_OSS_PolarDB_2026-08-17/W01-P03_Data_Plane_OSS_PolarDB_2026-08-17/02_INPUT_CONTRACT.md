# W01-P03 Input Contract

## Required from P00

- current DB inventory
- current OSS state
- current audio/evidence asset inventory
- duplicate authority findings
- Evidence Index

## Required from P01

- Current Canon
- Product Boundary
- Internal Systems
- Authority Order

## Required from P02

- Node Role Assignment
- Network Matrix
- Secret Ownership Matrix
- Deployment Boundary
- Target One Song Topology
- Architecture Decision Register

## Required decisions

P03 cannot proceed without:

- selected metadata DB role
- selected object storage role
- known credential ownership
- known network path from control/worker to DB/OSS

## Optional but useful

- existing DB DDL
- current worker filesystem layout
- current upload code
- current asset registry
- existing hash/version models
