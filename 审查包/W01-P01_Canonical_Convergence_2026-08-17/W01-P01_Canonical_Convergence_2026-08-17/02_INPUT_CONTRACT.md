# W01-P01 Input Contract

## Required P00 Inputs

| Input | Required | Purpose |
|---|---:|---|
| Executive Reality Summary | YES | 当前主链与最大冲突 |
| GitHub Repository Reality | YES | main / PR / branches / authority |
| Task Package Reality | YES | 避免把计划当能力 |
| Cloud Infrastructure Reality | YES | 防止 Canon 虚构 runtime |
| Data & External Capability Reality | YES | 防止产品文档虚构能力 |
| Truth Table | YES | 冲突逐项裁决 |
| Conflict/Unknown/Blocker List | YES | 未决问题 |
| Current System Map | YES | 现实 vs 目标分离 |
| Evidence Index | YES | 结论可追溯 |

## Input Validation

P01 在任何 mutation 之前必须生成：

`P00_INTAKE_CHECK.md`

内容：

- 每个输入路径
- hash / timestamp（若可得）
- 是否完整
- 是否存在明显互相矛盾
- 是否存在阻断 P01 的 UNKNOWN

## Critical Unknown Rule

如果 UNKNOWN 影响以下任何一项，必须停止相关决策：

- 当前 authoritative state machine
- 当前 production API authority
- 当前 deployed runtime identity
- 数据库真实 authority
- 用户明确要求保留/删除的关键产品面

停止形式：

`HUMAN_DECISION_REQUIRED`

不要猜。
