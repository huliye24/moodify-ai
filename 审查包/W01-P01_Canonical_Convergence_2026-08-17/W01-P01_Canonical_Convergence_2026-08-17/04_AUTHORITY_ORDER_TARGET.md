# Target Authority Order

> 最终以 P01 实际裁决为准；本文件是目标参考。

1. **Current explicit human instruction**
2. **Root `AGENTS.md`**
3. **`docs/canon/*`**
4. **Verified runtime evidence**
5. **Canonical main behavior + tests**
6. **Current subsystem documentation**
7. **Experimental documentation**
8. **Historical / legacy documentation**

## Clarification

### “人类指令”解决什么？

方向、产品边界、授权。

### “Runtime evidence”解决什么？

真实存在什么。

因此：

- 人类可以决定 Ear 不再对外
- 但不能通过一句产品指令让一个未部署的服务变成“已部署”

两者不能互相偷换。
